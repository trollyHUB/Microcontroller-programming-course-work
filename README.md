## Что это такое

**NEXIS Wellness Station** — умная настольная станция, которая в реальном времени следит за параметрами рабочей среды и помогает работать продуктивнее:

- Измеряет **температуру, влажность и давление** воздуха (BME280)
- Контролирует **качество воздуха / CO₂ / VOC** (Winsen ZM106-VOC)
- Отслеживает **освещённость** рабочего места (BH1750)
- Определяет **уровень шума** (KY-037)
- Фиксирует **присутствие человека** за столом (PIR HC-SR501)
- Ведёт **Pomodoro-таймер** (25/5, 50/10, 90/20 мин) с уведомлениями
- Отправляет все данные на **веб-дашборд** по Wi-Fi в реальном времени

## Быстрый старт

### 1. Веб-дашборд (без ESP32, demo-режим)

```bash
cd site/nexis-dashboard-v2/nexis-v2

# Установить зависимости
pip install fastapi uvicorn python-socketio aiofiles jinja2

# Запустить сервер
uvicorn main:socket_app --host 0.0.0.0 --port 5000 --reload
```

Открыть в браузере: **http://localhost:5000**  
Нажать кнопку **Demo** — сервер не нужен, данные генерируются автоматически.

Swagger API: **http://localhost:5000/docs**

---

### 2. ESP32 прошивка

#### Требования
- [PlatformIO](https://platformio.org/) (VS Code extension или CLI)
- ESP32 DevKit V1
- Подключённые датчики согласно схеме ниже

#### Настройка перед прошивкой

Откройте `esp32/src/config.h` и заполните свои данные:

```cpp
#define WIFI_SSID       "Название_вашей_WiFi"
#define WIFI_PASSWORD   "Пароль_WiFi"
#define SERVER_HOST     "192.168.X.X"   // IP вашего ПК (ipconfig → IPv4)
```

> **Никогда не коммитьте** реальные пароли в git!

#### Сборка и загрузка

```bash
cd esp32

pio run                          # только сборка (проверка)
pio run --target upload          # сборка + загрузка на плату
pio device monitor --baud 115200 # серийный монитор
```

## Схема подключения

### I2C шина (SDA=GPIO21, SCL=GPIO22)

| Устройство | I2C адрес | Питание |
|-----------|-----------|---------|
| BME280 (T/H/P) | 0x76 | 3.3V |
| BH1750 (свет) | 0x23 | 3.3V |
| LCD 1602 | 0x27 | **5V** |

### Другие соединения

| Датчик/устройство | GPIO | Питание |
|------------------|------|---------|
| Winsen ZM106-VOC RX | GPIO16 | **5V** |
| Winsen ZM106-VOC TX | GPIO17 | **5V** |
| PIR HC-SR501 | GPIO27 | **5V** |
| KY-037 (шум) | GPIO39 | 3.3V |
| DHT11 | GPIO4 | 3.3V |
| RGB LED (R/G/B) | GPIO13/12/14 | 3.3V |
| Зуммер | GPIO25 | 3.3V |
| Кнопка Mode | GPIO32 | — |
| Кнопка OK | GPIO33 | — |

## ZM106-VOC UART протокол

Датчик подключён к **Serial2** (RX=GPIO16, TX=GPIO17, 9600 baud).

```
Команда: FF 01 86 00 00 00 00 00 79  (9 байт)
Ответ:   FF 86 HH LL 00 00 00 00 CRC (9 байт)

CO₂ (ppm) = (HH << 8) | LL
CRC = (~(сумма байт 1..7)) + 1
```

## Возможности дашборда

- **3 режима:** Отключено / Demo (без ESP32) / Live (реальные данные)
- **6 карточек датчиков** с мини-графиками и индикаторами статуса
- **Главный график** — до 200 точек истории за выбранный период
- **Аналитика** — среднее, минимум, максимум, тренды
- **Pomodoro-таймер** — SVG-кольцо, звук, история сессий
- **Экспорт CSV** — совместим с Excel (UTF-8 BOM, разделитель `;`)
- **Тёмная тема** — сохраняется в localStorage
- **°C / °F** — переключатель единиц
