## ZM106 — ПРОТОКОЛ

```
Запрос: FF 01 86 00 00 00 00 00 79   (9 байт)
Ответ:  FF 86 HI LO 00 00 00 00 CRC  (9 байт)

ppm = (HI << 8) | LO
CRC = (~(byte1+...+byte7)) + 1   [дополнение до 2]
Таймаут: 500 мс
UART2: RX=GPIO16, TX=GPIO17, 9600 baud, 8N1
```

## ПРЕРЫВАНИЯ — СУТЬ ОТВЕТА

**"Зачем?"**
```
PIR движение = 0.3–0.5 с
ZM106 UART таймаут = 500 мс
HTTP POST сеть = 42+ мс

loop() может пропустить PIR при polling.
ISR ловит мгновенно — независимо от loop().
```

**"Как?"**
```cpp
volatile bool isrPIR = false;
void IRAM_ATTR onPIR() { isrPIR = true; }
attachInterrupt(digitalPinToInterrupt(27), onPIR, RISING);
// В loop: if (isrPIR) { ... isrPIR = false; }
```

**IRAM_ATTR** = код ISR в Internal RAM (не Flash) → нет задержки кэша, нет crash при Flash-операциях

**volatile** = каждое чтение из RAM, компилятор не кэширует в регистре

**debounce 200 мс** = защита от механического дребезга кнопок

## ЕСЛИ СПРОСЯТ НЕОЖИДАННОЕ

**"Сколько тока потребляет?"**
ESP32 Wi-Fi ~240 мА + PIR 65 мкА + BME280 3 мА + BH1750 0.2 мА + ZM106 100 мА + RGB ~18 мА + LCD ~15 мА = **~380–500 мА при 5V ≈ 2.5 Вт**. Питание USB 5V 2A — с запасом.

**"АЦП точность?"**
12-бит (0–4095). Погрешность до 10–15% на краях диапазона — нелинейность ESP32 ADC. Для KY-037 (шум) — допустимо, нужен только относительный уровень.

**"Почему не RTOS?"**
Для одного потока данных (один ESP32 → один сервер) кооперативная многозадачность через millis() достаточна. RTOS добавляет сложность без реального выигрыша в данном сценарии.

**"ADC2 почему не используете?"**
ADC2 конфликтует с Wi-Fi радиомодулем — возвращает мусор при активном Wi-Fi. Только ADC1 (GPIO32–39).

**"SD-карта?"**
Модуль есть в спецификации: SPI на GPIO5/23/19/18. В текущей версии не реализована — данные передаются по Wi-Fi в реальном времени. В перспективах — буфер при потере сети.

**"ZM106 — не настоящий CO₂?"**
Верно — это VOC-датчик (электрохимический). Коррелирует с CO₂ в офисных условиях. Истинный CO₂ — NDIR (SCD41). В перспективах — замена.

**"I2C vs SPI — почему I2C?"**
I2C: 2 провода на всю шину, все 3 устройства на них. SPI: 4 провода + по одному CS на устройство = 4+3 = 7 проводов. I2C экономит 5 GPIO и упрощает разводку.
