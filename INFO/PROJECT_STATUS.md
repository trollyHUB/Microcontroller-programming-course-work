## 🎯 ЧТО ТАКОЕ ПРОЕКТ

**NEXIS Wellness Station** — умная IoT-станция мониторинга для рабочего стола на базе ESP32.

Устройство в реальном времени измеряет параметры рабочей среды и помогает работать продуктивнее:
- Следит за температурой, влажностью, давлением воздуха
- Измеряет качество воздуха (VOC/CO2)
- Контролирует уровень освещённости и шума
- Определяет присутствие человека за столом
- Запускает Pomodoro таймер (25 мин работа / 5 мин отдых)
- Отправляет всё это на красивый веб-дашборд по WiFi

**Для кого:** Студент/программист/офисный работник — любой, кто хочет улучшить рабочее место.

### Датчики (основные)

| Датчик | Что измеряет | Интерфейс | Пины | Питание |
|---|---|---|---|---|
| **BME280** | Температура + Влажность + Давление | I2C | SDA=21, SCL=22 | 3.3V |
| **BH1750** | Освещённость (1–65535 lux) | I2C | SDA=21, SCL=22 | 3.3V |
| **Winsen ZM106-VOC** | Качество воздуха / VOC | UART 9600 | RX=16, TX=17 | **5V!** |
| **PIR HC-SR501** | Движение / присутствие человека | Digital | GPIO27 | **5V!** |
| **KY-037** | Уровень шума (относительный) | Analog | GPIO39 (ADC) | 3.3V |

### Дисплей и индикация

| Компонент | Назначение | Интерфейс | Пины | Питание |
|---|---|---|---|---|

## 🔑 КЛЮЧЕВЫЕ ТЕХНИЧЕСКИЕ МОМЕНТЫ

### Winsen ZM106-VOC — UART парсинг

```cpp
// Подключение: ESP32 RX←TX датчика, TX→RX датчика
HardwareSerial zm106(2);  // UART2

void setup() {
    zm106.begin(9600, SERIAL_8N1, 16, 17); // RX=16, TX=17
}

// Формат пакета (9 байт):
// [0xFF] [0x01] [XX] [XX] [XX] [XX] [CO2_H] [CO2_L] [CS]
int readZM106() {
    if (zm106.available() >= 9) {
        byte buf[9];
        zm106.readBytes(buf, 9);
        if (buf[0] == 0xFF && buf[1] == 0x01) {
            return (buf[6] << 8) | buf[7];  // ppm
        }
    }
    return -1;
}
```

### BME280 — I2C

```cpp
#include <Adafruit_BME280.h>
Adafruit_BME280 bme;

void setup() {
    if (!bme.begin(0x76)) {  // или 0x77 если не работает
        Serial.println("BME280 не найден!");
    }
}

float temp = bme.readTemperature();      // °C
float hum  = bme.readHumidity();         // %
float pres = bme.readPressure() / 100.0; // hPa
```

### JSON отправка на Flask

```cpp
String json = "{\"temperature\":" + String(temp, 1) +
              ",\"humidity\":"    + String(hum, 1) +
              ",\"co2\":"         + String(co2) +
              ",\"light\":"       + String(lux, 1) +
              ",\"noise\":"       + String(noise) +
              ",\"motion\":"      + String(pir) +
              ",\"pressure\":"    + String(pres, 2) + "}";

HTTPClient http;
http.begin("http://192.168.X.X:5000/api/data");  // IP компьютера!
http.addHeader("Content-Type", "application/json");
http.POST(json);
http.end();
```
