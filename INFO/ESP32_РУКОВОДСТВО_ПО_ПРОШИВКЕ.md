## 1. Что нужно установить

### Шаг 1 — VS Code
Скачайте и установите: https://code.visualstudio.com/

### Шаг 2 — PlatformIO IDE
1. Откройте VS Code
2. Нажмите **Extensions** (Ctrl+Shift+X)
3. Найдите **PlatformIO IDE**
4. Нажмите **Install**
5. Дождитесь установки (может занять 5–10 минут)
6. Перезапустите VS Code

### Шаг 3 — Драйвер USB для ESP32
ESP32 DevKit V1 использует чип **CP2102** или **CH340** для USB.

| Чип | Драйвер |
|-----|---------|
| CP2102 | https://www.silabs.com/developers/usb-to-uart-bridge-vcp-drivers |
| CH340  | https://www.wch-ic.com/downloads/CH341SER_EXE.html |

Как проверить, какой чип:
- Windows: Диспетчер устройств → Порты (COM и LPT)
- Если видите `Silicon Labs CP210x` — это CP2102
- Если видите `USB-SERIAL CH340` — это CH340

### Шаг 4 — Python (нужен для PlatformIO)
Если ещё не установлен: https://www.python.org/downloads/
При установке **обязательно** поставьте галочку **"Add Python to PATH"**

## 2. Настройка перед прошивкой

Откройте файл:
```
esp32/src/config.h
```

Найдите и измените **три строки**:

### 2.1 Имя вашей Wi-Fi сети
```cpp
#define WIFI_SSID       "YOUR_WIFI_SSID"    // ← Замените на имя вашей сети
```
Пример:
```cpp
#define WIFI_SSID       "HomeNetwork_2.4G"
```

> **Важно:** ESP32 работает только на частоте **2.4 GHz**.
> Если ваша сеть 5 GHz — создайте отдельную точку 2.4 GHz или используйте мобильный хотспот.

### 2.2 Пароль Wi-Fi
```cpp
#define WIFI_PASSWORD   "YOUR_WIFI_PASSWORD"  // ← Пароль от вашей сети
```
Пример:
```cpp
#define WIFI_PASSWORD   "mypassword123"
```

### 2.3 IP адрес компьютера с сервером
```cpp
#define SERVER_HOST     "192.168.1.100"   // ← IP вашего компьютера
```
Как узнать IP — смотрите раздел 3.

## 3. Как узнать IP компьютера

ESP32 отправляет данные на компьютер, где запущен FastAPI. Компьютер и ESP32 должны быть в **одной Wi-Fi сети**.

### Windows:
1. Нажмите **Win + R**, введите `cmd`, нажмите Enter
2. В командной строке введите:
```
ipconfig
```
3. Найдите раздел вашей Wi-Fi сети:
```
Беспроводная локальная сеть Wi-Fi:
   IPv4-адрес. . . . . . . . . . . . . . : 192.168.1.105
```
4. Это и есть ваш IP — `192.168.1.105`

> **Важно:** IP может меняться при каждом подключении. Чтобы зафиксировать его, назначьте **статический IP** в настройках роутера по MAC-адресу компьютера.

### Проверка соединения
После того как узнали IP, убедитесь что сервер доступен. В браузере на компьютере зайдите:
```
http://ВАШИХ_IP:5000/api/status
```
Должны увидеть JSON:
```json
{"status": "online", "server": "NEXIS Dashboard v2.0 (FastAPI)", ...}
```

## 4. Прошивка ESP32

### Шаг 1 — Запустите FastAPI сервер на компьютере
```bash
cd site/nexis-dashboard-v2/nexis-v2
uvicorn main:socket_app --host 0.0.0.0 --port 5000 --reload
```
Сервер должен быть запущен **до** того, как ESP32 начнёт отправлять данные.

### Шаг 2 — Подключите ESP32
Подключите ESP32 к компьютеру через USB кабель.

Проверьте, что он определился:
- Windows: Диспетчер устройств → Порты (COM и LPT) → должен появиться COM-порт (например, COM3)

### Шаг 3 — Откройте проект в VS Code
Откройте папку `NEXIS-Wellness-Complete/esp32/` через:
- **File → Open Folder** → выберите папку `esp32`

PlatformIO автоматически загрузит все библиотеки из `platformio.ini` при первом открытии.

### Шаг 4 — Загрузка прошивки
В нижней панели VS Code нажмите кнопку **→ Upload** (стрелка вправо).

Или через терминал (Ctrl+`):
```bash
pio run --target upload
```

Вывод при успешной прошивке:
```
Linking .pio/build/esp32dev/firmware.elf
...
Flash: [=======   ]  74.2% (used 972933 bytes from 1310720 bytes)
========================= [SUCCESS] Took 25 seconds =========================
```

### Шаг 5 — Мониторинг Serial
После прошивки откройте Serial Monitor:
```bash
pio device monitor --baud 115200
```
Или в VS Code нажмите кнопку с иконкой розетки (Serial Monitor).

Нормальный вывод при старте:

## 5. Проверка работы

### На дашборде
1. Откройте браузер: `http://localhost:5000`
2. В правом верхнем углу нажмите **Live** (или "Подключить")
3. Тайлы должны начать обновляться — данные приходят каждые 10 секунд

### Проверка API
```
GET http://localhost:5000/api/sensors    — последнее показание
GET http://localhost:5000/api/status     — статус сервера
```

### Что должно работать
- [ ] LCD показывает данные с датчиков
- [ ] RGB LED горит зелёным (всё в норме)
- [ ] Serial Monitor выводит данные каждые 10 сек
- [ ] На сайте `http://localhost:5000` данные обновляются в реальном времени
- [ ] `POST OK` в Serial Monitor — данные доходят до сервера

## 6. Схема подключения датчиков

### I2C шина (все на одних пинах GPIO21/GPIO22)

| Устройство | SDA | SCL | VCC | GND | I2C адрес |
|-----------|-----|-----|-----|-----|-----------|
| BME280 ⭐ | GPIO21 | GPIO22 | 3.3V | GND | **0x76** |
| BH1750 | GPIO21 | GPIO22 | 3.3V | GND | **0x23** |
| LCD 1602 ⭐ | GPIO21 | GPIO22 | 5V (VIN) | GND | **0x27** |

> Все три устройства подключаются параллельно к одним пинам SDA/SCL.
> У каждого свой I2C адрес — конфликтов нет.

### UART — Winsen ZM106-VOC ⭐ (основной CO₂)

| Контакт ZM106 | Пин ESP32 | Примечание |
|--------------|-----------|------------|
| TX | GPIO16 (RX2) | Данные от датчика |
| RX | GPIO17 (TX2) | Команды к датчику |
| VCC | VIN (5V) | Обязательно 5V, не 3.3V! |
| GND | GND | |

> ZM106-VOC работает только от **5V**. Подключайте к пину VIN на плате (не к 3V3!).

### Одиночные пины

| Датчик | GPIO | Тип сигнала | VCC |
|--------|------|------------|-----|
| DHT11 (доп.) | GPIO4 | Digital 1-Wire | 3.3V |
| PIR HC-SR501 | GPIO27 | Digital HIGH/LOW | 5V (VIN) |
| MQ-135 (доп.) | GPIO36 | Аналоговый ADC | 5V (VIN) |
| KY-037 (шум) | GPIO39 | Аналоговый ADC | 3.3V |
| RGB LED Red | GPIO13 | PWM | 3.3V (через 220Ом) |
| RGB LED Green | GPIO12 | PWM | 3.3V (через 220Ом) |
| RGB LED Blue | GPIO14 | PWM | 3.3V (через 220Ом) |
| Зуммер | GPIO25 | PWM | 3.3V (через 100Ом) |
| Кнопка Mode | GPIO32 | INPUT_PULLUP | — |
| Кнопка OK | GPIO33 | INPUT_PULLUP | — |

> **Кнопки:** подключайте один контакт к GPIO, второй к GND. Внутренний PULLUP включён в коде.

### Итог по питанию

| Питание | Устройства |
|---------|-----------|
| **3.3V** | BME280, BH1750, DHT11, KY-037, RGB LED, Зуммер |
| **5V (VIN)** | LCD 1602, Winsen ZM106-VOC, MQ-135, PIR HC-SR501 |

## 7. Что отображается на LCD

LCD автоматически переключает экраны каждые **3 секунды**. Кнопка **Mode** переключает вручную.

| Экран | Строка 1 | Строка 2 |
|-------|---------|---------|
| 0 | `Temp:  22.3 C` | `Hum:   45.2 %` |
| 1 | `CO2:  450 ppm` | `Press: 1013.5 hPa` |
| 2 | `Light:  320 lux` | `Noise:  35.2 dB` |
| 3 | `Motion: No` | `WiFi: Connected` |
| 4 | `Pomo [WORK] #1` | `Time: 24:35` |

## 8. Кнопки и управление

| Кнопка | GPIO | Функция |
|--------|------|---------|
| **Mode** | GPIO32 | Переключить экран LCD вперёд |
| **OK** | GPIO33 | Запустить Pomodoro / Остановить Pomodoro |

Кнопки подключаются между пином GPIO и GND. Антидребезг встроен в прошивку (200 мс).

## 9. RGB LED — значения цветов

| Цвет | Ситуация |
|------|---------|
| Синий мигающий | Нет подключения к Wi-Fi |
| Зелёный | Всё в норме, Wi-Fi подключён |
| Жёлтый | Предупреждение (CO2 > 800 ppm, или тихо, или шумно) |
| Красный | Опасность (CO2 > 1200 ppm, или температура > 30°C) |
| Зелёно-голубой | Работает Pomodoro (рабочий цикл) |
| Синий (не мигает) | Pomodoro перерыв |

## 10. Pomodoro таймер

Pomodoro — техника управления временем: 25 минут работы, 5 минут перерыва.

| Действие | Как выполнить |
|---------|--------------|
| Запустить рабочий цикл | Нажать кнопку **OK** |
| Остановить | Нажать кнопку **OK** ещё раз |
| Перерыв начнётся | Автоматически после 25 минут |
| Следующий цикл | Нажать **OK** после перерыва |

При завершении рабочего цикла:
- Зуммер сыграет мелодию
- LCD покажет "WORK DONE! Great"
- Данные отправятся на сервер (`POST /api/pomodoro`)
- На дашборде счётчик циклов увеличится

Поmodoro данные можно посмотреть на сайте: раздел **Pomodoro** → статистика за день.

## 11. Troubleshooting — решение проблем

### ESP32 не определяется в системе (нет COM-порта)
- Установите драйвер CP2102 или CH340 (см. раздел 1)
- Попробуйте другой USB кабель (некоторые кабели только для зарядки, без данных)
- Попробуйте другой USB порт

### BME280 ERROR на LCD
```
[ERR] BME280 NOT FOUND — check I2C wiring (0x76)
```
- Проверьте провода: SDA → GPIO21, SCL → GPIO22
- Проверьте питание: 3.3V (не 5V!)
- Запустите I2C сканер:
```cpp
// Временно вставьте в setup() для диагностики:
for (byte addr = 1; addr < 127; addr++) {
    Wire.beginTransmission(addr);
    if (Wire.endTransmission() == 0)
        Serial.printf("I2C device at: 0x%02X\n", addr);
}
```
Ожидаемый результат: `0x23` (BH1750), `0x27` (LCD), `0x76` (BME280)

### ZM106-VOC не отвечает
```
[WARN] ZM106-VOC: no response (may need warm-up)
```
Причины и решения:
1. **Датчик холодный** — ZM106 требует прогрева 1–2 минуты после включения. Подождите.
2. **Неправильные пины** — RX датчика → GPIO16 (RX2 ESP32), TX датчика → GPIO17 (TX2 ESP32)
3. **Нет питания 5V** — подключайте только к VIN (не к 3V3!)
4. **Перепутаны RX/TX** — попробуйте поменять провода местами

### Wi-Fi не подключается
```
[WiFi] Connection FAILED — working offline
```
Причины:
- Неправильный SSID или пароль в `config.h`
- Сеть работает на 5 GHz (ESP32 поддерживает только 2.4 GHz)
- ESP32 слишком далеко от роутера
- Попробуйте мобильный хотспот (2.4 GHz)

### Server POST: FAILED
```
[HTTP] POST failed: -1
```
Причины:
1. FastAPI сервер не запущен на компьютере
2. Неправильный IP в `config.h` (`SERVER_HOST`)
3. Брандмауэр Windows блокирует порт 5000

Решение брандмауэра Windows:
- Панель управления → Брандмауэр → Дополнительные параметры
- Правила для входящих подключений → Создать правило
- Тип: Порт → TCP → 5000 → Разрешить

Или в командной строке (от Администратора):
```
netsh advfirewall firewall add rule name="NEXIS FastAPI" dir=in action=allow protocol=TCP localport=5000
```

### Данные не появляются на сайте
- Убедитесь что в браузере включён режим **Live** (не Demo)
- Обновите страницу
- Проверьте: `http://localhost:5000/api/sensors` — должны быть свежие данные

### KY-037 показывает максимальный шум всегда
- Проверьте что подключён к GPIO39 (ADC1, только вход)
- GPIO39 не имеет PULLUP — нормально
- Настройте чувствительность потенциометром на плате KY-037

## Полезные команды PlatformIO

```bash
# Только сборка (без загрузки)
pio run

# Сборка и загрузка
pio run --target upload

# Serial монитор
pio device monitor --baud 115200

# Очистить кэш сборки
pio run --target clean

# Показать подключённые порты
pio device list
```
