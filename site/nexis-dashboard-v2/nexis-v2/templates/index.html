Введение

В современном мире значительная часть населения проводит рабочее время в закрытых помещениях перед компьютером. По статистике, офисные работники и IT-специалисты проводят более 8 часов в день в сидячем положении. При этом качество рабочей среды оказывает существенное влияние на здоровье и продуктивность человека.

Исследования показывают, что повышенный уровень CO₂ (более 1000 ppm) снижает когнитивные способности на 15–50%, недостаточная освещённость приводит к усталости глаз и снижению концентрации, а высокий уровень шума негативно сказывается на качестве выполняемой работы. Согласно данным ВОЗ, 76% IT-специалистов сталкиваются с профессиональным выгоранием, которое во многом обусловлено неправильной организацией рабочего пространства.

Актуальность данного проекта обусловлена необходимостью создания доступного и функционального инструмента для мониторинга параметров рабочего места и повышения личной продуктивности.

Цель работы — разработка интеллектуальной IoT-станции для мониторинга микроклимата рабочего места и управления продуктивностью на базе микроконтроллера ESP32.

Задачи проекта:

  • Изучить архитектуру микроконтроллера ESP32 и его возможности для IoT-разработки;
  • Выбрать и обосновать набор датчиков для мониторинга рабочей среды;
  • Разработать программное обеспечение для сбора, обработки и передачи данных;
  • Создать веб-интерфейс для визуализации данных в реальном времени;
  • Реализовать систему умных уведомлений и таймер Pomodoro;
  • Провести тестирование и оценку системы.

Объект исследования: система мониторинга параметров рабочей среды на базе микроконтроллера ESP32.

Предмет исследования: методы и алгоритмы сбора, обработки и визуализации данных с датчиков в IoT-системах.

Глава 1. Теоретическая часть

1.1 Обзор IoT-систем мониторинга рабочей среды

Интернет вещей (IoT, Internet of Things) — концепция вычислительной сети физических объектов («вещей»), оснащённых встроенными технологиями для взаимодействия друг с другом или с внешней средой. В контексте мониторинга рабочей среды IoT-системы позволяют собирать данные с множества датчиков, обрабатывать их и предоставлять пользователю в удобном формате.

На рынке существуют коммерческие аналоги: Xiaomi Air Quality Monitor (~$60), Netatmo Healthy Home Coach (~$100), Awair Element (~$200). Однако все они имеют существенные недостатки: высокую стоимость, закрытую архитектуру и отсутствие возможности настройки под конкретные нужды пользователя. Проект NEXIS Wellness Station предлагает открытую, расширяемую альтернативу стоимостью около 15 000 тенге.

1.2 Микроконтроллер ESP32

ESP32 — двухъядерный 32-битный микроконтроллер компании Espressif Systems, специально разработанный для IoT-приложений. Ключевые характеристики:

Выбор ESP32 обоснован встроенным WiFi-модулем, двухъядерной архитектурой (позволяет одновременно опрашивать датчики и обслуживать сеть), широкой экосистемой библиотек и доступной ценой (~1800 тенге).

1.3 Датчики и интерфейсы связи

В проекте используется шесть различных датчиков, подключённых через три различных интерфейса:

Интерфейс I2C (Inter-Integrated Circuit) — двухпроводной последовательный интерфейс, позволяющий подключить до 128 устройств на одну шину GPIO21/22. Через I2C подключены: основной датчик температуры/влажности/давления BME280 (0x76), датчик освещённости BH1750 (0x23) и дисплей LCD 1602 (0x27).

Цифровой/аналоговый интерфейс используется для: DHT11 — дополнительный датчик температуры и влажности (однопроводной протокол, GPIO4), PIR HC-SR501 — датчик присутствия (цифровой выход, GPIO27), KY-037 — датчик шума (аналоговый, GPIO39), MQ-135 — дополнительный датчик CO₂ (аналоговый, GPIO36).

Интерфейс UART применяется для основного датчика качества воздуха Winsen ZM106-VOC, который измеряет концентрацию CO₂ и летучих органических соединений (VOC). Датчик передаёт калиброванные данные пакетами со скоростью 9600 бод через GPIO16 (RX) и GPIO17 (TX).

2.2 Программная архитектура

Система состоит из двух основных программных компонентов: прошивки ESP32 на C++ и веб-сервера на Python Flask.

Прошивка ESP32 написана на C++ с использованием фреймворка Arduino. Основные модули:

  • Sensor Manager — опрашивает все датчики каждые 10 секунд: BME280 (I2C), Winsen ZM106-VOC (UART), BH1750 (I2C), KY-037 (ADC), PIR (Digital), с резервным чтением DHT11 и MQ-135;
  • WiFi Client — поддерживает соединение и автоматически переподключается;
  • HTTP Client — отправляет JSON с данными на FastAPI-сервер;
  • Telegram Bot — обрабатывает команды через HTTPS API;
  • Pomodoro Engine — управляет таймером 25/5 минут;
  • Display Manager — выводит данные на LCD 1602 в 4 режимах отображения.

Веб-сервер (FastAPI) обеспечивает асинхронный REST API для приёма данных от ESP32 и отдачи их браузеру. Данные хранятся в SQLite базе данных. Для передачи обновлений в реальном времени используется протокол WebSocket через библиотеку python-socketio.

2.3 Web-интерфейс

Веб-интерфейс разработан как одностраничное приложение (SPA) с боковым меню навигации. Технологический стек: HTML5, CSS3, JavaScript (ES6+), Chart.js (графики), Socket.IO (WebSocket).

Интерфейс включает следующие разделы: общий Dashboard с 6 карточками датчиков, отдельные страницы для каждого датчика с подробной информацией, таймер Pomodoro с тремя режимами работы, журнал событий с фильтрацией, страницу о проекте и данную страницу с курсовой работой.

Особенность реализации — три режима работы: Отключено (нет данных), Демо (имитация реальных данных) и ESP32 Live (реальные данные с платы через WebSocket).

Заключение

В ходе выполнения данной курсовой работы была разработана и реализована умная IoT-станция мониторинга рабочего места NEXIS Wellness Station на базе микроконтроллера ESP32. Система обеспечивает непрерывный контроль ключевых параметров рабочей среды: температуры, влажности, атмосферного давления, концентрации летучих органических соединений (VOC/CO₂), уровня освещённости, шума и присутствия человека.

В процессе работы были достигнуты все поставленные цели: спроектирована аппаратная часть устройства с использованием датчиков на интерфейсах I2C и UART, разработан веб-сервер на базе FastAPI (Python) с хранением данных в SQLite, реализован современный веб-интерфейс в виде одностраничного приложения (SPA) с тёмной и светлой темами, интерактивными графиками реального времени и таймером Pomodoro с интеграцией датчика присутствия.

Практическая ценность проекта состоит в том, что NEXIS Wellness Station позволяет пользователю объективно оценивать условия рабочей среды и своевременно принимать меры по их улучшению. Интеграция техники Pomodoro с датчиком движения PIR HC-SR501 обеспечивает автоматическую паузу таймера при отсутствии человека за рабочим местом — что является уникальной функцией, отсутствующей в стандартных Pomodoro-приложениях.

Дальнейшее развитие проекта может включать: добавление Telegram-бота для удалённых уведомлений, разработку мобильного приложения, интеграцию с системами умного дома (Home Assistant), а также применение алгоритмов машинного обучения для прогнозирования оптимального времени работы на основе накопленной статистики.

🏠 Home Assistant — Интеграция

NEXIS предоставляет endpoint в формате HA REST sensor. Все 7 показателей доступны как сенсоры в Home Assistant для автоматизаций умного дома.

1Откройте /api/ha-sensor — проверьте формат данных

3Добавьте блок и укажите IP вашего компьютера вместо SERVER_IP
sensor:
  - platform: rest
    resource: http://SERVER_IP:5000/api/ha-sensor
    name: "NEXIS CO2"
    value_template: "{% raw %}{{ value_json.co2 }}{% endraw %}"
    unit_of_measurement: "ppm"
    scan_interval: 30
