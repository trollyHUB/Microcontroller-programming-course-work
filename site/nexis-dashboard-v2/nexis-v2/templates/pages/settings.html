📱 Telegram Bot — Алерты

Бот автоматически отправляет сообщение при опасных показаниях датчиков и присылает ежедневную сводку в 18:00.

1Создайте бота через @BotFather в Telegram → получите токен
2Узнайте ваш Chat ID через @userinfobot
3Запустите сервер с переменными окружения:
set NEXIS_TELEGRAM_TOKEN=1234567890:ABC...
set NEXIS_TELEGRAM_CHAT_ID=123456789
python -m uvicorn main:socket_app --port 5000
Проверяем...
🏠 Home Assistant — Интеграция

NEXIS предоставляет endpoint в формате HA REST sensor.

1Откройте /api/ha-sensor — проверьте формат данных
2В Home Assistant откройте configuration.yaml
3Добавьте блок и укажите IP вашего компьютера вместо SERVER_IP
sensor:
  - platform: rest
    resource: http://SERVER_IP:5000/api/ha-sensor
    name: "NEXIS CO2"
    value_template: "{% raw %}{{ value_json.co2 }}{% endraw %}"
    unit_of_measurement: "ppm"
    scan_interval: 30
🔗 Открыть /api/ha-sensor
📱 Установить как приложение (PWA)

NEXIS можно установить как обычное приложение на телефон или компьютер — без App Store.

1Откройте дашборд в Google Chrome или Edge
2В адресной строке справа нажмите иконку «Установить» (⊕)
3На Android: Меню → «Добавить на главный экран»
