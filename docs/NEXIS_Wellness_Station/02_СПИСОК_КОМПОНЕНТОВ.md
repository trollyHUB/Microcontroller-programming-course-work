# ⚠️ ВАЖНЫЕ ЗАМЕЧАНИЯ

## При покупке ESP32:

1. ✅ Выбирайте **DevKit V1** с **30 пинами** (не 38!)
2. ✅ С **USB Micro** или **USB-C** (не старый Mini)
3. ✅ С **CP2102** или **CH340** чипом (драйверы есть)

## При покупке датчиков:

1. ✅ DHT22 лучше DHT11 (точнее)
2. ✅ BH1750 — именно **FVI** версия (I2C)
3. ✅ MQ-135 — требует прогрева 24-48 часов!

## При покупке дисплея:

1. ✅ OLED **SSD1306** (не SH1106!)
2. ✅ Разрешение **128x64** (не 128x32)
3. ✅ Интерфейс **I2C** (4 пина: GND, VCC, SCL, SDA)
