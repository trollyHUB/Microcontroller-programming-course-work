# 🛠️ ЭТАП 1: ПОДГОТОВКА ESP32

## Шаг 1.1: Проверка ESP32

1. Подключите ESP32 к компьютеру через USB
2. Должен загореться красный светодиод питания
3. Проверьте, что ESP32 определяется в системе

**Windows:**
```powershell
# Откройте Диспетчер устройств
devmgmt.msc

# Найдите: Порты (COM и LPT)
# Должно быть: Silicon Labs CP210x USB to UART Bridge (COMx)
```

**Если драйвера нет:**
- Скачайте с сайта Silicon Labs: CP210x USB Driver
- Установите драйвер

## Шаг 1.2: Первая прошивка (тест)

Создайте тестовый проект в PlatformIO:

```cpp
// test_blink.cpp
void setup() {
  pinMode(2, OUTPUT);
}

void loop() {
  digitalWrite(2, HIGH);
  delay(1000);
  digitalWrite(2, LOW);
  delay(1000);
}
```

Загрузите в ESP32. Должен мигать встроенный LED.

# 🔌 ЭТАП 2: УСТАНОВКА КОМПОНЕНТОВ НА МАКЕТКУ

## Шаг 2.1: Размещение ESP32

```
Макетная плата (вид сверху):
┌─────────────────────────────────────────────┐
│  a b c d e    f g h i j                     │
│  │ │ │ │ │ ─  │ │ │ │ │                     │
│ 1○ ○ ○ ○ ○    ○ ○ ○ ○ ○                     │
│ 2○ ○ ○ ○ ○    ○ ○ ○ ○ ○                     │
│ 3○ ○ ○ ○ ○    ○ ○ ○ ○ ○                     │
│  ...                                        │
│ 10○ ○ ○ ○ ○    ○ ○ ○ ○ ○  ← ESP32 здесь    │
│ 11○ ○ ○ ○ ○    ○ ○ ○ ○ ○                   │
│  ...                                        │
│ 25○ ○ ○ ○ ○    ○ ○ ○ ○ ○                   │
│                                             │
│  +  [═══════════════]  -    ← Шины питания │
│  +  [═══════════════]  -                    │
└─────────────────────────────────────────────┘
```

**Важно:** 
- ESP32 должен быть по центру
- Пины слева и справа от центральной прорези
- НЕ вставляйте силой — должно входить легко!

## Шаг 2.2: Подключение питания

1. **Красный провод:** VIN (ESP32) → + (красная шина)
2. **Черный провод:** GND (ESP32) → - (синяя шина)
3. **Красный провод:** 3V3 (ESP32) → + (вторая красная шина, если есть)

**Схема:**
```
ESP32          Шина питания
VIN  ──────► + (5V)
3V3  ──────► + (3.3V) [отдельная шина]
GND  ──────► - (GND)
GND  ──────► - (GND) [соедините обе земли!]
```

# 📡 ЭТАП 3: ПОДКЛЮЧЕНИЕ ДАТЧИКОВ

## Шаг 3.1: DHT22 (температура и влажность)

### Схема подключения:
```
DHT22          ESP32
┌─────┐
│  1  │ VCC ──────► 3V3
│  2  │ DATA ─────► GPIO4 (D4)
│  3  │ NC (не подключать)
│  4  │ GND ──────► GND
└─────┘

+ Резистор 4.7K между DATA и VCC!
```

### Инструкция:
1. Вставьте DHT22 в макетку (4 пина)
2. Красный провод: пин 1 (VCC) → 3V3
3. Желтый провод: пин 2 (DATA) → GPIO4
4. Черный провод: пин 4 (GND) → GND
5. **Резистор 4.7K:** между пином 2 и VCC

---

## Шаг 3.2: MQ-135 (качество воздуха)

### Схема:
```
MQ-135         ESP32
VCC ──────► VIN (5V)
GND ──────► GND
A0  ──────► GPIO36 (VP)
D0  (не используем)
```

### Инструкция:
1. Вставьте MQ-135 в макетку
2. Красный провод: VCC → VIN (5V)
3. Черный провод: GND → GND
4. Желтый провод: A0 → GPIO36

⚠️ **Важно:** MQ-135 требует прогрев 24-48 часов!

---

## Шаг 3.3: BH1750 (освещённость)

### Схема:
```
BH1750         ESP32
VCC ──────► 3V3
GND ──────► GND
SCL ──────► GPIO22 (D22) ┐
SDA ──────► GPIO21 (D21) ├─ I2C шина
ADDR ─────► GND          │
```

### Инструкция:
1. Вставьте BH1750 в макетку
2. Красный провод: VCC → 3V3
3. Черный провод: GND → GND
4. Белый провод: SCL → GPIO22
5. Синий провод: SDA → GPIO21
6. ADDR → GND (для адреса 0x23)

---

## Шаг 3.4: PIR HC-SR501 (движение)

### Схема:
```
PIR            ESP32
VCC ──────► VIN (5V)
OUT ──────► GPIO27 (D27)
GND ──────► GND
```

### Настройка PIR:
```
Вид сверху PIR:
┌─────────────┐
│   [Time]    │ ← Потенциометр времени (мин)
│             │
│   [Sens]    │ ← Потенциометр чувствительности (макс)
│             │
│  [L] [H]    │ ← Джампер (поставьте на H)
└─────────────┘
```

### Инструкция:
1. Настройте PIR: Time = min, Sens = max, Джампер = H
2. Красный провод: VCC → VIN (5V)
3. Желтый провод: OUT → GPIO27
4. Черный провод: GND → GND

---

## Шаг 3.5: KY-037 (звук)

### Схема:
```
KY-037         ESP32
VCC ──────► 3V3
GND ──────► GND
A0  ──────► GPIO39 (VN)
D0  ──────► GPIO26 (D26) [опционально]
```

### Инструкция:
1. Вставьте KY-037 в макетку
2. Красный провод: VCC → 3V3
3. Черный провод: GND → GND
4. Желтый провод: A0 → GPIO39
5. (Опционально) Синий: D0 → GPIO26

# 🖥️ ЭТАП 4: ДИСПЛЕЙ И ИНДИКАЦИЯ

## Шаг 4.1: OLED SSD1306

### Схема:
```
OLED           ESP32
GND ──────► GND
VCC ──────► 3V3
SCL ──────► GPIO22 (D22) ┐ Общая I2C шина
SDA ──────► GPIO21 (D21) ┘ с BH1750
```

### Инструкция:
1. Вставьте OLED в макетку
2. Черный провод: GND → GND
3. Красный провод: VCC → 3V3
4. Белый провод: SCL → GPIO22 (та же линия, что BH1750!)
5. Синий провод: SDA → GPIO21 (та же линия, что BH1750!)

---

## Шаг 4.2: Зуммер

### Схема:
```
BUZZER         ESP32
+ ──────► GPIO25 (D25)
- ──────► GND
```

### Инструкция:
1. Красный провод: + → GPIO25
2. Черный провод: - → GND

---

## Шаг 4.3: RGB LED

### Схема (с резисторами):
```
RGB LED (общий катод)
       ┌─────┐
R ─────┤     ├─ [220Ω] ─► GPIO13
G ─────┤ LED ├─ [220Ω] ─► GPIO12
B ─────┤     ├─ [220Ω] ─► GPIO14
K(-) ──┤     ├─────────► GND
       └─────┘
```

### Инструкция:
1. Вставьте RGB LED в макетку (самая длинная нога = K = GND)
2. Резистор 220Ω от R → GPIO13
3. Резистор 220Ω от G → GPIO12
4. Резистор 220Ω от B → GPIO14
5. K (катод) → GND

**Определение ног LED:**
```
Вид снизу (плоская сторона слева):
┌───────┐
│   ─   │ ← Плоская сторона
│ │││││ │
└─┬┬┬┬──┘
  ││││
  RGBK
  
R = Red (красный)
G = Green (зелёный)
B = Blue (синий)
K = Katod (общий -, самый длинный)
```

# 🎮 ЭТАП 5: КНОПКИ УПРАВЛЕНИЯ

## Шаг 5.1: Подключение кнопок

### Схема (с внутренним PULLUP):
```
Кнопка 1 (MODE):
GPIO32 ──┬─── Button ─── GND
         │
    (PULLUP внутри ESP32 к 3.3V)

Кнопка 2 (OK):
GPIO33 ──┬─── Button ─── GND
         │
    (PULLUP)

Кнопка 3 (CANCEL):
GPIO5 ───┬─── Button ─── GND
         │
    (PULLUP)
```

### Инструкция:
1. Вставьте 3 кнопки в макетку
2. Кнопка 1: одна нога → GPIO32, другая → GND
3. Кнопка 2: одна нога → GPIO33, другая → GND
4. Кнопка 3: одна нога → GPIO5, другая → GND

**Никаких резисторов не нужно!** (используем INPUT_PULLUP)

# ✅ ЭТАП 6: ПРОВЕРКА ПОДКЛЮЧЕНИЯ

## Шаг 6.1: Визуальная проверка

Проверьте каждое соединение:

- [ ] ESP32 подключен к макетке
- [ ] VIN → + (5V шина)
- [ ] 3V3 → + (3.3V шина или отдельные датчики)
- [ ] GND → - (общая земля)
- [ ] DHT22: 4 провода + резистор 4.7K
- [ ] MQ-135: 3 провода (VCC, GND, A0)
- [ ] BH1750: 5 проводов (VCC, GND, SCL, SDA, ADDR)
- [ ] PIR: 3 провода
- [ ] KY-037: 3-4 провода
- [ ] OLED: 4 провода (общая I2C с BH1750)
- [ ] Зуммер: 2 провода
- [ ] RGB LED: 4 провода + 3 резистора 220Ω
- [ ] Кнопки: 3 кнопки по 2 провода

## Шаг 6.2: Проверка мультиметром

1. **Питание:**
   - Между VIN и GND: ~5V
   - Между 3V3 и GND: ~3.3V

2. **Короткое замыкание:**
   - Между VIN и GND: должно быть >1 кОм
   - Между 3V3 и GND: должно быть >1 кОм

⚠️ **Если <100 Ом = КОРОТКОЕ ЗАМЫКАНИЕ! НЕ ВКЛЮЧАЙТЕ!**

## Шаг 6.3: Тест I2C сканером

Загрузите тестовый код:

```cpp
#include <Wire.h>

void setup() {
  Serial.begin(115200);
  Wire.begin(21, 22); // SDA, SCL
  
  delay(2000);
  Serial.println("\nI2C Scanner");
  
  byte count = 0;
  for (byte i = 1; i < 127; i++) {
    Wire.beginTransmission(i);
    if (Wire.endTransmission() == 0) {
      Serial.printf("Found device at 0x%02X\n", i);
      count++;
    }
  }
  
  if (count == 0) {
    Serial.println("No I2C devices found!");
  } else {
    Serial.printf("\nTotal: %d devices\n", count);
  }
}

void loop() {}
```

**Ожидаемый результат:**
```
I2C Scanner
Found device at 0x23  // BH1750
Found device at 0x3C  // OLED SSD1306

Total: 2 devices
```
