# ⚠️ ВАЖНЫЕ ЗАМЕЧАНИЯ

## 1. MQ-135 — требует прогрева!

```
⚠️ Датчик MQ-135 нужно прогреть 24-48 часов 
   перед первым точным измерением!
   
   Во время прогрева показания будут нестабильны.
```

## 2. PIR датчик — настройка

```
На PIR HC-SR501 есть 2 потенциометра:

1. Sensitivity (чувствительность) — крутить по часовой
2. Time delay (задержка) — минимум для быстрого отклика

Также есть джампер:
- H: Повторный триггер
- L: Одиночный триггер

Рекомендация: режим H
```

## 3. Уровни напряжения

```
⚠️ ESP32 GPIO работают на 3.3V!
   НЕ подавать 5V на GPIO напрямую!
   
   MQ-135 A0 выдаёт 0-5V, но:
   - GPIO36 (VP) толерантен до 3.6V
   - При 5V на входе использовать делитель напряжения!
```

### Делитель напряжения для MQ-135:

```
    MQ-135 A0 ─────┬─────[10KΩ]───── 5V (выход)
                   │
                   ├─────────────── GPIO36 (вход)
                   │
                  [20KΩ]
                   │
                  GND
```

Формула: `Vout = Vin × R2/(R1+R2) = 5V × 20K/30K = 3.33V` ✅

# 🧪 ПРОВЕРКА ПОДКЛЮЧЕНИЯ

## Тест I2C сканером:

```cpp
#include <Wire.h>

void setup() {
  Serial.begin(115200);
  Wire.begin(21, 22); // SDA, SCL
  
  Serial.println("Scanning I2C...");
  
  for (byte addr = 1; addr < 127; addr++) {
    Wire.beginTransmission(addr);
    if (Wire.endTransmission() == 0) {
      Serial.printf("Found: 0x%02X\n", addr);
    }
  }
}

void loop() {}
```

**Ожидаемый результат:**
```
Found: 0x23  // BH1750
Found: 0x3C  // OLED
```
