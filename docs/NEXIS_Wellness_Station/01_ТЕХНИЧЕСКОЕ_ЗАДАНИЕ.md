# 2. НАЗНАЧЕНИЕ И ЦЕЛИ

## 2.1 Назначение системы

NEXIS Wellness Station предназначена для:

1. **Мониторинга параметров микроклимата** рабочего места
2. **Повышения личной продуктивности** через технику Pomodoro
3. **Контроля здоровья** при работе за компьютером
4. **Своевременного оповещения** о неблагоприятных условиях

## 2.2 Цели создания

| № | Цель | Описание |
|---|------|----------|
| 1 | Образовательная | Изучение программирования микроконтроллеров ESP32 |
| 2 | Практическая | Создание реального IoT-устройства |
| 3 | Научная | Исследование влияния микроклимата на продуктивность |
| 4 | Коммерческая | Прототип для возможной коммерциализации |

# 3. ТРЕБОВАНИЯ К СИСТЕМЕ

## 3.1 Функциональные требования

### 3.1.1 Мониторинг микроклимата

| № | Параметр | Датчик | Диапазон | Точность |
|---|----------|--------|----------|----------|
| 1 | Температура | DHT22 | -40...+80°C | ±0.5°C |
| 2 | Влажность | DHT22 | 0-100% | ±2% |
| 3 | Качество воздуха (VOC) | Winsen ZM106-VOC | 0-500 ppm | ±5% |
| 4 | Качество воздуха (CO2, резерв) | MQ-135 | 10-1000 ppm | Относительная |
| 5 | Освещённость | BH1750 | 1-65535 lux | ±1 lux |
| 6 | Уровень шума | KY-037 | 30-120 dB | Относительная |
| 7 | Движение (присутствие) | PIR HC-SR501 | 3-7 м | — |

### 3.1.2 Управление продуктивностью

| № | Функция | Описание |
|---|---------|----------|
| 1 | Pomodoro таймер | Циклы 25 мин работа / 5 мин отдых |
| 2 | Трекинг сидения | Напоминание встать каждые 60-120 мин |
| 3 | Статистика | Подсчёт рабочих часов, перерывов |
| 4 | Отчёты | Дневные и недельные отчёты в Telegram |

### 3.1.3 Уведомления и оповещения

| № | Событие | Тип уведомления |
|---|---------|-----------------|
| 1 | Высокий CO2 (>1000 ppm) | Telegram + звук |
| 2 | Низкая освещённость (<300 lux) | Telegram |
| 3 | Долгое сидение (>2 часа) | Telegram + звук |
| 4 | Завершение Pomodoro | Telegram + звук |
| 5 | Высокий шум | Telegram |

### 3.1.4 Telegram Bot

| Команда | Описание |
|---------|----------|
| `/start` | Запуск бота, приветствие |
| `/status` | Текущие показатели всех датчиков |
| `/pomodoro` | Запуск Pomodoro таймера |
| `/stop` | Остановка таймера |
| `/stats` | Статистика за день |
| `/week` | Статистика за неделю |
| `/settings` | Настройки порогов |
| `/help` | Справка по командам |
| `/mode` | Переключение режимов работы |
| `/graph` | График параметров за день |
| `/achievements` | Достижения и очки |

### 3.1.5 Интеллектуальные функции

| № | Функция | Описание |
|---|---------|----------|
| 1 | Адаптивные пороги | Автоматическая подстройка порогов уведомлений на основе 7-дневной истории |
| 2 | Анализ трендов | Обнаружение ухудшения/улучшения параметров во времени |
| 3 | Предиктивные уведомления | Предупреждение о будущих проблемах на основе текущих трендов |
| 4 | Корреляционный анализ | Выявление связей между параметрами и продуктивностью |
| 5 | Многорежимная работа | Автоматическое переключение между режимами Work/Break/Away/Night/Focus |
| 6 | Web-интерфейс | Локальный веб-сервер с графиками и управлением (IP ESP32:80) |
| 7 | REST API | Программный интерфейс для интеграции с другими системами |
| 8 | Геймификация | Система очков, достижений и мотивационных уведомлений |
| 9 | Хранение истории | Сохранение данных на SD-карту (30 дней истории) |
| 10 | OTA обновления | Обновление прошивки по воздуху без подключения кабеля |

### 3.1.6 Режимы работы системы

| Режим | Активация | Особенности |
|-------|-----------|-------------|
| **Work Mode** | Обнаружено присутствие | Полный мониторинг, все уведомления, Pomodoro активен |
| **Break Mode** | После завершения Pomodoro | Релаксационные подсказки, напоминания о разминке |
| **Away Mode** | Нет движения >15 мин | Пониженное энергопотребление, редкий опрос датчиков |
| **Night Mode** | 22:00-07:00 или темно | Отключение звука, только критические уведомления |
| **Focus Mode** | Вручную через кнопку/Telegram | Отключение всех уведомлений кроме Pomodoro |

# 4. ТЕХНИЧЕСКИЕ ХАРАКТЕРИСТИКИ

## 4.1 Аппаратная платформа

| Компонент | Характеристики |
|-----------|----------------|
| **Микроконтроллер** | ESP32 DevKit V1 |
| **Процессор** | Xtensa dual-core 240 МГц |
| **RAM** | 520 КБ |
| **Flash** | 4 МБ |
| **Wi-Fi** | 802.11 b/g/n |
| **Bluetooth** | BLE 4.2 |

## 4.2 Датчики

| Датчик | Интерфейс | Напряжение |
|--------|-----------|------------|
| DHT22 | 1-Wire | 3.3-5V |
| MQ-135 | Analog | 5V |
| BH1750 | I2C | 3.3-5V |
| PIR HC-SR501 | Digital | 5V |
| KY-037 | Analog + Digital | 3.3-5V |

## 4.3 Периферия

| Компонент | Интерфейс |
|-----------|-----------|
| OLED SSD1306 128x64 | I2C |
| Зуммер пассивный | PWM |
| RGB LED | GPIO |
| Кнопки тактовые (x3) | GPIO |

## 4.4 Питание

| Параметр | Значение |
|----------|----------|
| Входное напряжение | 5V DC |
| Потребляемый ток (макс) | 500 мА |
| Разъём питания | Micro USB / USB-C |
| Резервное питание | Опционально (Li-Ion) |
