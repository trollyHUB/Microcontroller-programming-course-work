## 📋 О ПРОЕКТЕ

**NEXIS Wellness Station** — это **интеллектуальное IoT-устройство** для мониторинга параметров окружающей среды и повышения личной продуктивности. Устройство не просто измеряет параметры, но и **обучается**, **адаптируется** под пользователя и **предсказывает** проблемы до их возникновения.

### 🆕 Что нового в версии 2.0:
- ✅ **Профессиональный VOC датчик** Winsen ZM106 (UART)
- ✅ **Адаптивные пороги** с машинным обучением
- ✅ **5 режимов работы** (Work/Break/Away/Night/Focus)
- ✅ **Web-интерфейс** с графиками реального времени
- ✅ **REST API** для интеграции
- ✅ **Геймификация** (очки, достижения)
- ✅ **Хранение истории** на SD-карте (30 дней)

## 🎯 ЦЕЛИ ПРОЕКТА

1. Разработать **интеллектуальное** IoT-устройство для рабочего стола
2. Реализовать **адаптивный** мониторинг микроклимата
3. Внедрить технику Pomodoro с **многорежимной работой**
4. Создать систему **умных уведомлений** через Telegram Bot
5. Обеспечить **аналитику** с трендами и корреляциями
6. Разработать **Web-интерфейс** для визуализации
