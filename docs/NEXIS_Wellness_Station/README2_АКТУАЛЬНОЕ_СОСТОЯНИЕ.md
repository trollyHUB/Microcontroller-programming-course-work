## 🔌 I2C ШИНА — АКТУАЛЬНАЯ СХЕМА

Все три I2C устройства на одной шине (SDA=GPIO21, SCL=GPIO22):

```
GPIO21 (SDA) ────┬──── BME280  (адрес 0x76)
                 ├──── BH1750  (адрес 0x23)  [ADDR → GND]
                 └──── LCD 1602 (адрес 0x27) [с модулем PCF8574]

GPIO22 (SCL) ────┴──── все три устройства
```

**Ожидаемый результат I2C-сканера:**
```
Found: 0x23  ← BH1750
Found: 0x27  ← LCD 1602
Found: 0x76  ← BME280
```

## 🔑 КЛЮЧЕВЫЕ ФРАГМЕНТЫ КОДА (актуальные компоненты)

### BME280 (I2C, 0x76)

```cpp
#include <Adafruit_BME280.h>
Adafruit_BME280 bme;

void setup() {
    if (!bme.begin(0x76)) Serial.println("BME280 не найден!");
}
float temp = bme.readTemperature();      // °C
float hum  = bme.readHumidity();         // %
float pres = bme.readPressure() / 100.0; // hPa
```

### LCD 1602 (I2C, 0x27)

```cpp
#include <LiquidCrystal_I2C.h>
LiquidCrystal_I2C lcd(0x27, 16, 2);  // адрес, столбцы, строки

void setup() {
    lcd.init();
    lcd.backlight();
    lcd.setCursor(0, 0);
    lcd.print("NEXIS Station");
}
```

### Winsen ZM106-VOC (UART2)

```cpp
HardwareSerial zm106(2);  // UART2

void setup() {
    zm106.begin(9600, SERIAL_8N1, 16, 17);  // RX=16, TX=17
}

int readZM106() {
    byte cmd[] = {0xFF, 0x01, 0x86, 0, 0, 0, 0, 0, 0x79};
    zm106.write(cmd, 9);
    delay(500);
    if (zm106.available() >= 9) {
        byte buf[9];
        zm106.readBytes(buf, 9);
        if (buf[0] == 0xFF && buf[1] == 0x86) {
            return (buf[2] << 8) | buf[3];  // ppm
        }
    }
    return -1;
}
```

### JSON → FastAPI дашборд

```cpp
String json = "{\"temperature\":" + String(temp, 1) +
              ",\"humidity\":"    + String(hum, 1) +
              ",\"pressure\":"    + String(pres, 1) +
              ",\"co2\":"         + String(co2) +
              ",\"light\":"       + String(lux, 1) +
              ",\"noise\":"       + String(noise) +
              ",\"motion\":"      + String(pir ? 1 : 0) + "}";

HTTPClient http;
http.begin("http://192.168.X.X:5000/api/data");  // IP компьютера!
http.addHeader("Content-Type", "application/json");
int code = http.POST(json);
http.end();
```
