# 🎛️ 1. МИКРОКОНТРОЛЛЕР

## Требования к микроконтроллеру для нашего проекта:
- ✅ WiFi (для Telegram и веб-сервера)
- ✅ Достаточно GPIO пинов (минимум 15)
- ✅ I2C, UART, SPI интерфейсы
- ✅ Минимум 100 KB RAM (для веб-сервера + Telegram)
- ✅ Поддержка FreeRTOS (многозадачность)
- ✅ Поддержка прерываний

---

## Вариант A: ESP32 DevKit V1 (30 pin) ⭐ РЕКОМЕНДУЕТСЯ

```
┌─────────────────────────────────────┐
│  ○ ○ ○ ○ ○ ○ ○ ○ ○ ○ ○ ○ ○ ○ ○    │
│ ┌─────────────────────────────────┐ │
│ │         ESP32-WROOM-32          │ │
│ │           DevKit V1             │ │
│ │    [USB]    [EN] [BOOT]         │ │
│ └─────────────────────────────────┘ │
│  ○ ○ ○ ○ ○ ○ ○ ○ ○ ○ ○ ○ ○ ○ ○    │
└─────────────────────────────────────┘
        30 пинов (стандартная)
```

| Параметр | Значение |
|----------|----------|
| **CPU** | Xtensa dual-core 240 MHz |
| **RAM** | 520 KB SRAM |
| **Flash** | 4 MB |
| **WiFi** | 802.11 b/g/n |
| **Bluetooth** | v4.2 BR/EDR + BLE |
| **GPIO** | 25 (из 30 пинов) |
| **ADC** | 18 каналов (12-bit) |
| **UART** | 3 порта |
| **I2C** | 2 порта |
| **SPI** | 4 порта |
| **Напряжение** | 3.3V (питание 5V через USB) |
| **Цена Kaspi** | 3,000-4,000₸ |
| **Цена AliExpress** | 1,500-2,000₸ |

**✅ Преимущества:**
- Самый популярный → много примеров кода и библиотек
- Двухъядерный → одно ядро для WiFi, второе для логики
- Много GPIO → подключим все 8 датчиков
- FreeRTOS из коробки
- Отличная документация

**❌ Недостатки:**
- Потребляет больше энергии (~240 mA при WiFi)
- Некоторые GPIO имеют ограничения (GPIO 34-39 только input)

**🎓 Для курсовой:** ⭐⭐⭐⭐⭐ — **ЛУЧШИЙ ВЫБОР**

# 🌡️ 2. ДАТЧИК ТЕМПЕРАТУРЫ И ВЛАЖНОСТИ

## Требования:
- ✅ Температура: -10...+50°C (офисные условия)
- ✅ Влажность: 20-90%
- ✅ Точность: ±1°C и ±5%
- ✅ Цифровой выход (не аналоговый)

---

## Вариант A: DHT22 (AM2302) ⭐ РЕКОМЕНДУЕТСЯ

```
┌─────────┐
│  DHT22  │
│ ┌─────┐ │
│ │ /// │ │  ← Сетка (датчик влажности)
│ │ /// │ │
│ └─────┘ │
│ 1 2 3 4 │
└─┴─┴─┴─┴─┘
  V D N G
  C A C N
  C T   D
    A
```

| Параметр | Значение |
|----------|----------|
| **Температура** | -40...+80°C |
| **Точность T** | ±0.5°C |
| **Влажность** | 0-100% |
| **Точность RH** | ±2-5% |
| **Интерфейс** | 1-Wire (цифровой) |
| **Напряжение** | 3.3-5V |
| **Время отклика** | 2 секунды |
| **Цена Kaspi** | 1,500-2,500₸ |
| **Цена AliExpress** | 800-1,200₸ |

**✅ Преимущества:**
- Хорошая точность для цены
- Простое подключение (3 провода)
- Много библиотек и примеров
- Надёжный, проверенный временем

**❌ Недостатки:**
- Медленный (опрос раз в 2 сек)
- Протокол 1-Wire требует точного тайминга

**🎓 Для курсовой:** ⭐⭐⭐⭐⭐ — Отличный выбор

---

## Вариант B: DHT11 — ДЕШЕВЛЕ, НО ХУЖЕ

| Параметр | DHT22 | DHT11 |
|----------|-------|-------|
| **Температура** | -40...+80°C | 0...+50°C |
| **Точность T** | ±0.5°C | ±2°C |
| **Влажность** | 0-100% | 20-80% |
| **Точность RH** | ±2-5% | ±5% |
| **Цена** | 800-2,500₸ | 300-800₸ |

**❌ Почему хуже:**
- Низкая точность (±2°C — можно не заметить перегрев)
- Узкий диапазон влажности
- **Не подходит для "профессионального" проекта**

**🎓 Для курсовой:** ⭐⭐ — Слишком простой

---

## Вариант C: BME280 — 3 В 1 ⭐ АЛЬТЕРНАТИВА

```
┌───────────────┐
│    BME280     │
│   ┌───────┐   │
│   │  ///  │   │
│   └───────┘   │
│ VCC GND SCL SDA │
└──┴───┴───┴───┴──┘
```

| Параметр | DHT22 | BME280 |
|----------|-------|--------|
| **Температура** | ±0.5°C | ±1°C |
| **Влажность** | ±2-5% | ±3% |
| **Давление** | ❌ | ✅ 300-1100 hPa |
| **Интерфейс** | 1-Wire | I2C/SPI |
| **Скорость** | 0.5 Hz | До 157 Hz |
| **Цена** | 800-2,500₸ | 800-1,800₸ |

**✅ Преимущества BME280:**
- **3 в 1:** температура + влажность + давление
- I2C интерфейс (проще, надёжнее)
- Быстрее (можно опрашивать чаще)
- Дешевле или такая же цена
- Давление — бонус для прогноза погоды

**❌ Недостатки:**
- Чуть менее точный по влажности

**🎓 Для курсовой:** ⭐⭐⭐⭐⭐ — **ОТЛИЧНАЯ АЛЬТЕРНАТИВА**

### 2. Проверка I2C адресов
```cpp
// I2C Scanner — найти адреса датчиков
#include <Wire.h>

void setup() {
  Wire.begin();
  Serial.begin(9600);
  Serial.println("I2C Scanner");
}

void loop() {
  for (byte address = 1; address < 127; address++) {
    Wire.beginTransmission(address);
    if (Wire.endTransmission() == 0) {
      Serial.print("Found: 0x");
      Serial.println(address, HEX);
    }
  }
  delay(5000);
}
```

# 💻 ПЕРВЫЙ КОД — НАЧНЁМ СЕЙЧАС!

## Тест ESP32 + WiFi + Telegram (когда получишь ESP32)

Создай файл `src/main.cpp`:

```cpp
/*
 * NEXIS Wellness Station
 * Тестовый код — WiFi + Telegram
 * Версия: 0.1
 */

#include <Arduino.h>
#include <WiFi.h>
#include <WiFiClientSecure.h>
#include <UniversalTelegramBot.h>

// ========== НАСТРОЙКИ (ИЗМЕНИ!) ==========
const char* WIFI_SSID = "ТВОЙ_WIFI";           // Имя WiFi сети
const char* WIFI_PASSWORD = "ТВОЙ_ПАРОЛЬ";     // Пароль WiFi
const char* BOT_TOKEN = "ТВОЙ_ТОКЕН_БОТА";     // Токен от @BotFather
const char* CHAT_ID = "ТВОЙ_CHAT_ID";          // ID чата (узнаем позже)
// =========================================

WiFiClientSecure client;
UniversalTelegramBot bot(BOT_TOKEN, client);

// Встроенный LED на ESP32
#define LED_BUILTIN 2

void setup() {
  Serial.begin(115200);
  Serial.println("\n\n=== NEXIS Wellness Station ===");
  Serial.println("Версия: 0.1 (тест WiFi + Telegram)");
  
  // Настройка LED
  pinMode(LED_BUILTIN, OUTPUT);
  
  // Подключение к WiFi
  Serial.print("Подключение к WiFi: ");
  Serial.println(WIFI_SSID);
  
  WiFi.begin(WIFI_SSID, WIFI_PASSWORD);
  
  int attempts = 0;
  while (WiFi.status() != WL_CONNECTED && attempts < 30) {
    digitalWrite(LED_BUILTIN, !digitalRead(LED_BUILTIN));  // Мигаем
    delay(500);
    Serial.print(".");
    attempts++;
  }
  
  if (WiFi.status() == WL_CONNECTED) {
    Serial.println("\n✅ WiFi подключен!");
    Serial.print("IP адрес: ");
    Serial.println(WiFi.localIP());
    digitalWrite(LED_BUILTIN, HIGH);  // LED горит = подключено
    
    // Отправляем тестовое сообщение в Telegram
    client.setInsecure();  // Для HTTPS без сертификата
    
    String message = "🚀 *NEXIS Wellness Station*\n\n";
    message += "✅ Устройство запущено!\n";
    message += "📶 WiFi: " + String(WIFI_SSID) + "\n";
    message += "🌐 IP: " + WiFi.localIP().toString() + "\n";
    message += "\nВерсия: 0.1 (тест)";
    
    if (bot.sendMessage(CHAT_ID, message, "Markdown")) {
      Serial.println("✅ Telegram сообщение отправлено!");
    } else {
      Serial.println("❌ Ошибка отправки в Telegram");
    }
  } else {
    Serial.println("\n❌ Не удалось подключиться к WiFi!");
    digitalWrite(LED_BUILTIN, LOW);
  }
}

void loop() {
  // Пока пусто — добавим код позже
  delay(1000);
}
```

4. Скопируй этот ID
