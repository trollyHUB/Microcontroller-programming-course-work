## Ключевые требования (кратко)

### Объём и оформление
- **25–35 страниц** (без приложений)
- Шрифт: **Times New Roman 14 пт**
- Межстрочный интервал: **полуторный**
- Поля: **лево 35 мм, право 10 мм, верх/низ 20 мм**
- Нумерация страниц: правый верхний угол, начиная со страницы 2
- Абзацный отступ: **1.25 см**, выравнивание по ширине

### Структура курсовой работы
1. Титульный лист
2. Содержание
3. Введение
4. Глава 1 — Теоретическая часть (анализ литературы, обзор)
5. Глава 2 — Практическая часть (схемы, код, реализация)
6. Глава 3 — (при необходимости)
7. Заключение
8. Список литературы (не менее 5 источников, издания последних 5 лет)
9. Приложения

### Защита
- Доклад: **8–10 минут**
- **Обязательна презентация** в PowerPoint
- Ответы на вопросы
- Допускаются только работы, оформленные по требованиям
