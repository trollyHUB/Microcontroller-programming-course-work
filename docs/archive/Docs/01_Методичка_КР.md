# Методические рекомендации по курсовой работе

## Дисциплина: PM3304 «Программирование микроконтроллеров»
## Образовательная программа: 6B06104 - «Вычислительная техника и программное обеспечение»

---

## Основные требования

### Структура курсовой работы:
1. **Титульный лист**
2. **Содержание**
3. **Введение** (актуальность, цель, задачи, объект, предмет)
4. **Основная часть** (минимум 2 главы):
   - Глава 1: Теоретические основы
   - Глава 2: Практическая часть (схемы, алгоритмы, код)
5. **Заключение**
6. **Список литературы** (минимум 5 источников, предпочтительно последние 5 лет)
7. **Приложения**

### Требования к оформлению:
- **Объём:** 25-35 страниц
- **Шрифт:** Times New Roman 14 пт
- **Интервал:** полуторный
- **Поля:** левое 35мм, правое 10мм, верхнее/нижнее 20мм
- **Абзацный отступ:** 1,25 см

### Защита:
- Доклад 8-10 минут
- Презентация PowerPoint (обязательно!)
- Демонстрация работающего устройства
