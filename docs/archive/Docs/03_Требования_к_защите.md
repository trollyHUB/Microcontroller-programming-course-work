# 🎓 Требования к защите курсовой работы

## Что нужно подготовить:

### 1. Пояснительная записка (25-35 страниц)
- [ ] Титульный лист (по образцу из методички)
- [ ] Содержание с нумерацией страниц
- [ ] Введение (актуальность, цель, задачи)
- [ ] Глава 1 - Теория
- [ ] Глава 2 - Практика (схемы, фото)
- [ ] Глава 3 - Программная часть (алгоритмы, код)
- [ ] Заключение
- [ ] Список литературы (мин. 5 источников)
- [ ] Приложения (листинги кода, схемы)

### 2. Презентация PowerPoint (ОБЯЗАТЕЛЬНО!)
- [ ] 10-15 слайдов
- [ ] Титульный слайд
- [ ] Актуальность и цель
- [ ] Задачи
- [ ] Схема устройства
- [ ] Фото собранного устройства
- [ ] Скриншоты ПО
- [ ] Демонстрация работы (видео/гиф)
- [ ] Выводы
- [ ] Спасибо за внимание

### 3. Работающее устройство
- [ ] Собранный прототип
- [ ] Рабочая прошивка
- [ ] Приложение/Web-интерфейс (по теме)

### 4. Исходный код
- [ ] Код для микроконтроллера
- [ ] Код приложения (если есть)
- [ ] Комментарии в коде

---

## Процедура защиты:

1. **Доклад:** 8-10 минут
2. **Вопросы:** от комиссии и группы
3. **Демонстрация:** показать работу устройства

## Критерии оценки:

| Критерий | Вес |
|----------|-----|
| Работоспособность устройства | 30% |
| Качество кода | 20% |
| Оформление документации | 20% |
| Качество презентации | 15% |
| Ответы на вопросы | 15% |

---

## Сроки:
- **Срок сдачи:** определяется учебным графиком (уточнить у руководителя!)
- **Доработка:** срок устанавливается руководителем
