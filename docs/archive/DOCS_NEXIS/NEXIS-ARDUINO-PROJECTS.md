# 🔧 Arduino-проекты для экосистемы NEXIS

## Введение

Данный документ содержит идеи IoT-проектов на базе Arduino/ESP32, которые могут быть интегрированы в экосистему NEXIS. Каждый проект соответствует современным тенденциям и может стать частью курсовой/дипломной работы.

## 🏆 ТОП-10 проектов для NEXIS

### 1. 🌱 NEXIS GreenHouse — Умная теплица
**Статус:** Выбран для курсовой работы

**Описание:** Автоматизированная система управления микроклиматом теплицы с удалённым мониторингом.

**Компоненты:**
- Arduino Uno / ESP32
- DHT22 (температура + влажность)
- Датчик влажности почвы
- Датчик освещённости (BH1750)
- Реле для управления поливом/вентиляцией
- LCD дисплей / OLED

**Интеграция с NEXIS:**
- Данные отправляются на NEXIS Cloud
- Управление через NEXIS App
- Уведомления через NEXIS Bot (Telegram)
- История на NEXIS Dashboard

**Бюджет:** ~15,000-25,000 ₸
**Сложность:** ⭐⭐⭐☆☆

---

### 2. 🚪 NEXIS Access — Умный замок с RFID
**Описание:** Система контроля доступа с учётом посетителей и интеграцией с NEXIS ID.

**Компоненты:**
- Arduino Nano / ESP32
- RFID модуль RC522
- Электромагнитный замок
- Сервопривод
- Зуммер + LED индикаторы

**Интеграция с NEXIS:**
- Авторизация через NEXIS ID
- Логи доступа в NEXIS Cloud
- Push-уведомления при входе
- Управление правами через Dashboard

**Бюджет:** ~10,000-20,000 ₸
**Сложность:** ⭐⭐⭐☆☆

---

### 3. 🌡️ NEXIS Weather — Домашняя метеостанция
**Описание:** Сбор метеоданных с публикацией в облако и визуализацией.

**Компоненты:**
- ESP32 (со встроенным WiFi)
- BME280 (температура, влажность, давление)
- Датчик качества воздуха MQ-135
- УФ-датчик
- E-Paper дисплей

**Интеграция с NEXIS:**
- Публичные данные на NEXIS Maps
- Персональная статистика в профиле
- Сравнение с другими станциями сети

**Бюджет:** ~12,000-18,000 ₸
**Сложность:** ⭐⭐☆☆☆

---

### 4. 🐾 NEXIS Pet — Автоматическая кормушка
**Описание:** Умная кормушка для домашних животных с расписанием и мониторингом.

**Компоненты:**
- Arduino Nano / ESP8266
- Сервопривод для дозатора
- Тензодатчик (вес корма)
- RTC модуль (часы реального времени)
- Камера ESP32-CAM (опционально)

**Интеграция с NEXIS:**
- Расписание кормления в NEXIS App
- Уведомления о низком уровне корма
- Видеонаблюдение через NEXIS
- Статистика питания питомца

**Бюджет:** ~8,000-15,000 ₸
**Сложность:** ⭐⭐⭐☆☆

---

### 5. 💡 NEXIS Light — Умное освещение
**Описание:** Система управления освещением с датчиками присутствия и автоматизацией.

**Компоненты:**
- ESP32 / Arduino + WiFi модуль
- PIR датчик движения
- Датчик освещённости
- Реле / MOSFET для управления
- RGB LED лента (WS2812B)

**Интеграция с NEXIS:**
- Управление через NEXIS App
- Автоматические сценарии
- Интеграция с "Эффект присутствия"
- Энергомониторинг

**Бюджет:** ~7,000-12,000 ₸
**Сложность:** ⭐⭐☆☆☆

### 6. 🔐 NEXIS Safe — Сейф с биометрией
**Описание:** Умный сейф с отпечатком пальца и удалённым мониторингом.

**Компоненты:**
- Arduino Mega / ESP32
- Сканер отпечатков пальцев (R307)
- Соленоидный замок
- Датчик вибрации/удара
- Зуммер сигнализации

**Интеграция с NEXIS:**
- Привязка отпечатков к NEXIS ID
- Оповещения о попытках взлома
- История открытий
- Экстренная блокировка через App

**Бюджет:** ~15,000-25,000 ₸
**Сложность:** ⭐⭐⭐⭐☆

### 7. 🚗 NEXIS Track — GPS трекер
**Описание:** Устройство отслеживания местоположения с отправкой координат в облако.

**Компоненты:**
- Arduino Nano / ESP32
- GPS модуль (NEO-6M)
- GSM/GPRS модуль (SIM800L)
- Аккумулятор Li-Po
- Акселерометр (детекция движения)

**Интеграция с NEXIS:**
- Отображение на NEXIS Maps
- История маршрутов
- Геозоны с уведомлениями
- Режим SOS

**Бюджет:** ~12,000-20,000 ₸
**Сложность:** ⭐⭐⭐⭐☆

### 8. 🏠 NEXIS Home — Центр умного дома
**Описание:** Хаб для управления всеми IoT устройствами в доме.

**Компоненты:**
- ESP32 (основной контроллер)
- nRF24L01 (связь с устройствами)
- IR передатчик/приёмник
- Реле модули
- Touchscreen дисплей

**Интеграция с NEXIS:**
- Единая точка управления
- Голосовой помощник
- Автоматизация сценариев
- Интеграция всех NEXIS IoT устройств

**Бюджет:** ~20,000-35,000 ₸
**Сложность:** ⭐⭐⭐⭐⭐

### 9. 💧 NEXIS Aqua — Умный аквариум
**Описание:** Автоматизация аквариума с контролем параметров воды.

**Компоненты:**
- Arduino Uno / ESP32
- Датчик температуры DS18B20 (водонепроницаемый)
- pH датчик
- Датчик мутности воды
- Автокормушка
- LED освещение

**Интеграция с NEXIS:**
- Мониторинг параметров воды
- Автоматическое кормление по расписанию
- Уведомления о проблемах
- Камера наблюдения

**Бюджет:** ~18,000-30,000 ₸
**Сложность:** ⭐⭐⭐⭐☆

### 10. 🌞 NEXIS Solar — Солнечный трекер
**Описание:** Система автоматического поворота солнечной панели для максимальной эффективности.

**Компоненты:**
- Arduino Nano
- Фоторезисторы (4 шт.) или датчик освещённости
- Сервоприводы (2 оси)
- Солнечная панель
- Контроллер заряда

**Интеграция с NEXIS:**
- Мониторинг выработки энергии
- Статистика эффективности
- Оптимизация через ML (машинное обучение)
- Сравнение с другими станциями

**Бюджет:** ~15,000-25,000 ₸
**Сложность:** ⭐⭐⭐☆☆

## 🎯 Рекомендации для курсовой работы

### Лучший выбор: NEXIS GreenHouse (Умная теплица)

**Почему это хороший выбор:**

1. ✅ **Актуальность** — Smart Agriculture в тренде
2. ✅ **Практическая польза** — реальное применение в Казахстане
3. ✅ **Доступность компонентов** — всё можно купить
4. ✅ **Умеренная сложность** — выполнимо за семестр
5. ✅ **Интеграция с NEXIS** — показывает работу экосистемы
6. ✅ **Масштабируемость** — можно развить в дипломную

### Как усилить проект для защиты:

```
Базовая версия (курсовая):
├── Arduino + датчики
├── Локальное управление
└── Простой веб-интерфейс

Расширенная версия (диплом):
├── ESP32 + облако NEXIS
├── Мобильное приложение
├── Telegram бот
├── Machine Learning для оптимизации
└── Сеть из нескольких теплиц
```
