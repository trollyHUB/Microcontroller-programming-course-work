## 1️⃣ ВВЕДЕНИЕ

### Актуальность проекта

В современном мире **Интернет вещей (IoT)** становится неотъемлемой частью повседневной жизни. Умные дома, автоматизация, удалённый мониторинг — эти технологии позволяют:

- 🏠 Контролировать состояние помещений дистанционно
- 📊 Собирать и анализировать данные об окружающей среде
- ⚡ Экономить ресурсы (электричество, отопление)
- 🛡️ Повышать безопасность (датчики движения, задымления)

### Цель проекта

Разработать **недорогое, компактное IoT-устройство** для мониторинга параметров микроклимата в помещении с возможностью:

1. Измерения 6 параметров среды
2. Локального отображения данных
3. Отправки данных на сервер по Wi-Fi
4. Настройки через веб-интерфейс
5. Интеграции в экосистему NEXIS

## 2️⃣ ТЕХНИЧЕСКОЕ ОПИСАНИЕ

### 2.1 Измеряемые параметры

| № | Параметр | Датчик | Диапазон |
|---|----------|--------|----------|
| 1 | Температура | DHT22 | -40°C ... +80°C |
| 2 | Влажность | DHT22 | 0% ... 100% |
| 3 | Атм. давление | BMP280 | 300 ... 1100 hPa |
| 4 | Качество воздуха | MQ-135 | CO2, NH3, NOx |
| 5 | Освещённость | BH1750 | 1 ... 65535 lx |
| 6 | Движение | PIR HC-SR501 | Да/Нет |

### 2.2 Аппаратная платформа

**Микроконтроллер: ESP8266 NodeMCU**

```
Характеристики:
├── CPU: Tensilica L106 32-bit @ 80/160 MHz
├── RAM: 80 KB
├── Flash: 4 MB
├── Wi-Fi: 802.11 b/g/n
├── GPIO: 17 выводов
├── ADC: 1 канал (10 бит)
├── I2C, SPI, UART
└── Питание: 5V через USB или 3.3V
```

**Почему ESP8266?**
- ✅ Встроенный Wi-Fi (не нужен отдельный модуль)
- ✅ Совместимость с Arduino IDE
- ✅ Низкая стоимость (~2500 тг)
- ✅ Большое сообщество и документация
- ✅ Достаточно мощный для IoT задач

## 5️⃣ ИНТЕГРАЦИЯ С NEXIS

### Что такое NEXIS?

**NEXIS** — это масштабная IT-экосистема, разрабатываемая для интеграции в повседневную жизнь людей. Платформа включает модули:

- **NEXIS ID** — единая система идентификации
- **NEXIS Home** — умный дом (данный проект)
- **NEXIS Social** — социальная сеть
- **NEXIS AI** — искусственный интеллект
- И другие...

### Роль данного проекта

Данный курсовой проект является **первым физическим устройством** в экосистеме NEXIS, демонстрируя:

1. Возможность интеграции IoT устройств
2. API для обмена данными
3. Масштабируемость системы
4. Практическое применение технологий
