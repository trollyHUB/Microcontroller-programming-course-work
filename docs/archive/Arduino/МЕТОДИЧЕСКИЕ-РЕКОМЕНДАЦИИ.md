## 🎯 ВЫБРАННАЯ ТЕМА

### NEXIS Home Sensor Hub

**Соответствует темам:**
- Тема 4: Метеостанция с публикацией на web-сервере
- Тема 6: Прототип теплицы на Arduino

**Наша интерпретация:**
```
IoT Sensor Hub для умного дома с интеграцией в платформу NEXIS

Измеряемые параметры:
├── Температура (DHT22)
├── Влажность (DHT22)
├── Атм. давление (BMP280)
├── Качество воздуха (MQ-135)
├── Освещённость (BH1750)
└── Движение (PIR)

Функции:
├── Локальный OLED дисплей
├── Wi-Fi передача данных
├── REST API интеграция
├── Web-интерфейс настройки
└── OTA обновления
```
