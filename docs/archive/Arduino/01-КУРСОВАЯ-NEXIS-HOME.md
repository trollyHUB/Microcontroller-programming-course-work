## 📊 ФУНКЦИОНАЛЬНОСТЬ ПРОЕКТА

### Что измеряет:
```
📊 Температура:    -40°C до +80°C (точность ±0.5°C)
💧 Влажность:      0-100% (точность ±2%)
🌡️ Давление:       300-1100 hPa (точность ±1 hPa)
🌬️ Качество воздуха: CO2, TVOC (если есть CCS811)
```

### Что делает:
```
✅ Измеряет показатели каждые 30 секунд
✅ Выводит данные на OLED дисплей
✅ Отправляет данные на веб-сервер
✅ Показывает графики в браузере
✅ Уведомляет при критических значениях
✅ Хранит историю измерений
```

### Веб-интерфейс:
```
📱 Просмотр текущих показателей
📊 Графики за день/неделю/месяц
⚙️ Настройка порогов оповещения
📲 Уведомления в Telegram (опционально)
🔌 Управление реле (вентилятор)
```

## 🔧 ТЕХНОЛОГИЧЕСКИЙ СТЕК

### Микроконтроллер:
- **ESP32** — WiFi, Bluetooth, двухъядерный процессор
- **Arduino IDE** или **PlatformIO** — среда разработки
- **C/C++** — язык программирования

### Веб-часть:
- **Backend:** Python (Flask) или Node.js
- **Frontend:** HTML, CSS, JavaScript, Chart.js
- **База данных:** SQLite или PostgreSQL
- **Протокол:** HTTP REST API или MQTT

### Интеграция с NEXIS:
- REST API для отправки данных
- Авторизация через NEXIS ID (JWT токены)
- Webhook для уведомлений

## 🚀 ДРУГИЕ ИДЕИ ДЛЯ КУРСОВЫХ ПРОЕКТОВ (ARDUINO + NEXIS)

### 1. NEXIS Gate — Умный замок
```
Компоненты: ESP32, RFID RC522, серводвигатель, реле
Функции: 
- Открытие по карте/телефону
- Логирование входов в NEXIS
- Уведомления владельцу
- Временные коды доступа
```

### 2. NEXIS Track — GPS трекер
```
Компоненты: ESP32, NEO-6M GPS, SIM800L
Функции:
- Отслеживание местоположения
- История перемещений
- Геозоны и уведомления
- Интеграция с NEXIS Maps
```

### 3. NEXIS Plant — Умный уход за растениями
```
Компоненты: ESP32, датчик влажности почвы, помпа
Функции:
- Автополив по расписанию
- Мониторинг влажности
- Уведомления о поливе
- История ухода
```

### 4. NEXIS Air — Очиститель воздуха
```
Компоненты: ESP32, CCS811, вентилятор, фильтр
Функции:
- Мониторинг качества воздуха
- Автовключение при загрязнении
- Статистика в NEXIS
```

### 5. NEXIS Guard — Охранная система
```
Компоненты: ESP32, PIR датчик, камера, сирена
Функции:
- Обнаружение движения
- Фото при срабатывании
- Push уведомления
- Режимы (дома/ушёл)
```

### 6. NEXIS Light — Умное освещение
```
Компоненты: ESP32, реле, датчик освещённости
Функции:
- Управление светом
- Автоматика по времени/датчику
- Сценарии освещения
- Голосовое управление
```

### 7. NEXIS Meter — Счётчик воды/электричества
```
Компоненты: ESP32, датчик тока/расхода
Функции:
- Учёт потребления
- Графики и статистика
- Прогноз счёта
- Уведомления о превышении
```

### 8. NEXIS Doorbell — Умный звонок
```
Компоненты: ESP32-CAM, кнопка, динамик
Функции:
- Видео при звонке
- Уведомление на телефон
- Двусторонняя связь
- Запись посетителей
```
