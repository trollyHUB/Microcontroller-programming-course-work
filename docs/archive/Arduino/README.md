## 🎯 О ПРОЕКТЕ

**NEXIS Home Sensor Hub** — это IoT устройство для мониторинга микроклимата помещения, интегрированное в экосистему NEXIS.

### Функции:
- 🌡️ Измерение температуры (-40...+80°C)
- 💧 Измерение влажности (0-100%)
- 🌀 Измерение атмосферного давления
- 🌬️ Контроль качества воздуха (CO2, NH3)
- 🔆 Измерение освещённости
- 👤 Датчик движения
- 📡 Отправка данных на сервер по Wi-Fi
- 📺 Локальный OLED дисплей
- 🌐 Веб-интерфейс для настройки

### Технологии:
- ESP8266 NodeMCU (микроконтроллер)
- Arduino IDE (среда разработки)
- C/C++ (язык программирования)
- Wi-Fi, HTTP, REST API (сетевые протоколы)
- JSON (формат данных)
- I2C, SPI (протоколы связи)

## 🚀 БЫСТРЫЙ СТАРТ

1. Купите компоненты (см. СПИСОК-ПОКУПОК)
2. Установите Arduino IDE
3. Настройте поддержку ESP8266
4. Установите библиотеки
5. Соберите схему
6. Загрузите прошивку
7. Настройте Wi-Fi через портал
