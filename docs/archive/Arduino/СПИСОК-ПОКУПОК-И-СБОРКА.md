## 💻 ПРОГРАММНОЕ ОБЕСПЕЧЕНИЕ

### 1. Arduino IDE

**Скачать:** https://www.arduino.cc/en/software

**Настройка ESP8266:**
1. Откройте Arduino IDE
2. Файл → Настройки
3. В поле "Дополнительные ссылки для менеджера плат" добавьте:
   ```
   http://arduino.esp8266.com/stable/package_esp8266com_index.json
   ```
4. Инструменты → Плата → Менеджер плат
5. Найдите "esp8266" и установите
6. Выберите плату: "NodeMCU 1.0 (ESP-12E Module)"

### 2. Драйвер CH340

**Скачать:** https://www.wch.cn/download/CH341SER_EXE.html

Нужен для связи компьютера с ESP8266.

### 3. Необходимые библиотеки

В Arduino IDE: Скетч → Подключить библиотеку → Управление библиотеками

Установить:
- [ ] DHT sensor library (by Adafruit)
- [ ] Adafruit Unified Sensor
- [ ] Adafruit BMP280 Library
- [ ] BH1750 (by Christopher Laws)
- [ ] Adafruit SSD1306
- [ ] Adafruit GFX Library
- [ ] ArduinoJson (by Benoit Blanchon)
- [ ] WiFiManager (by tzapu)

### Визуальная схема

```
                         ESP8266 NodeMCU
                    ┌────────────────────┐
           3.3V ───┤ 3V3           VIN  ├─── 5V
            GND ───┤ GND           GND  ├─── GND
                   ┤ TX            RST  ├
                   ┤ RX            EN   ├
  DHT22 DATA ─────┤ D5 (GPIO14)   3V3  ├
   PIR OUT ───────┤ D6 (GPIO12)   GND  ├
BUZZER + ─────────┤ D7 (GPIO13)   CLK  ├
BUTTON ───────────┤ D3 (GPIO0)    SD0  ├
 LED_R ───────────┤ D4 (GPIO2)    CMD  ├
                   ┤ GND           SD1  ├
                   ┤ 3V3           SD2  ├
I2C SDA ──────────┤ D2 (GPIO4)    SD3  ├
I2C SCL ──────────┤ D1 (GPIO5)    RSV  ├
 LED_G ───────────┤ D8 (GPIO15)   RSV  ├
MQ135 A0 ─────────┤ A0            RSV  ├
 LED_B ───────────┤ D0 (GPIO16)   RSV  ├
                    └────────────────────┘

I2C ШИНА (D1, D2):
├── OLED SSD1306
├── BMP280
└── BH1750
```

## 📋 ПОШАГОВАЯ СБОРКА

### Этап 1: Проверка ESP8266 (30 мин)

1. Подключите ESP8266 к компьютеру через USB
2. Откройте Arduino IDE
3. Выберите плату: Инструменты → Плата → NodeMCU 1.0
4. Выберите порт: Инструменты → Порт → COM_X
5. Откройте пример: Файл → Примеры → ESP8266 → Blink
6. Загрузите (кнопка →)
7. Светодиод на плате должен мигать

### Этап 2: Подключение дисплея (30 мин)

1. Подключите OLED:
   - VCC → 3.3V
   - GND → GND
   - SDA → D2
   - SCL → D1

2. Загрузите тестовый скетч:
```cpp
#include <Wire.h>
#include <Adafruit_SSD1306.h>

Adafruit_SSD1306 display(128, 64, &Wire, -1);

void setup() {
  Wire.begin(D2, D1);
  display.begin(SSD1306_SWITCHCAPVCC, 0x3C);
  display.clearDisplay();
  display.setTextColor(WHITE);
  display.setTextSize(2);
  display.setCursor(0, 0);
  display.println("NEXIS");
  display.println("Home");
  display.display();
}

void loop() {}
```

### Этап 3: Подключение DHT22 (20 мин)

1. Подключите DHT22:
   - VCC → 3.3V
   - DATA → D5 (+ резистор 10K между DATA и VCC)
   - GND → GND

2. Тестовый код:
```cpp
#include <DHT.h>
DHT dht(D5, DHT22);

void setup() {
  Serial.begin(115200);
  dht.begin();
}

void loop() {
  float t = dht.readTemperature();
  float h = dht.readHumidity();
  Serial.printf("Temp: %.1f°C, Humidity: %.1f%%\n", t, h);
  delay(2000);
}
```

### Этап 4: Подключение остальных датчиков (40 мин)

Подключайте по одному и тестируйте!

**BMP280 (давление):**
```cpp
#include <Adafruit_BMP280.h>
Adafruit_BMP280 bmp;

void setup() {
  Serial.begin(115200);
  bmp.begin(0x76);
}

void loop() {
  Serial.printf("Pressure: %.1f hPa\n", bmp.readPressure()/100);
  delay(1000);
}
```

**BH1750 (свет):**
```cpp
#include <BH1750.h>
BH1750 lightMeter;

void setup() {
  Serial.begin(115200);
  Wire.begin(D2, D1);
  lightMeter.begin();
}

void loop() {
  Serial.printf("Light: %.1f lux\n", lightMeter.readLightLevel());
  delay(1000);
}
```

**MQ-135 (воздух):**
```cpp
void setup() {
  Serial.begin(115200);
}

void loop() {
  int airQuality = analogRead(A0);
  Serial.printf("Air quality: %d\n", airQuality);
  delay(1000);
}
```

### Этап 5: Загрузка основной прошивки (20 мин)

1. Откройте файл `nexis_home_sensor_hub.ino`
2. Установите все библиотеки (если не установлены)
3. Нажмите "Загрузить"
4. Дождитесь завершения
5. Откройте Монитор порта (115200 бод)

### Этап 6: Настройка Wi-Fi (10 мин)

1. После загрузки устройство создаст Wi-Fi точку "NEXIS_Home_Setup"
2. Подключитесь к ней с телефона
3. Откроется страница настройки
4. Введите данные вашего Wi-Fi
5. Устройство перезагрузится и подключится

### Этап 7: Проверка работы (10 мин)

1. Найдите IP адрес устройства:
   - Посмотрите на OLED дисплее
   - Или в мониторе порта
2. Откройте браузер: `http://IP_АДРЕС/`
3. Должна открыться веб-страница с данными

## ⚠️ ВОЗМОЖНЫЕ ПРОБЛЕМЫ

### Не загружается прошивка
- Проверьте выбор платы и порта
- Установите драйвер CH340
- Попробуйте другой USB кабель
- Удерживайте кнопку FLASH на плате при загрузке

### Дисплей не показывает
- Проверьте подключение I2C (SDA, SCL)
- Попробуйте адрес 0x3D вместо 0x3C
- Проверьте напряжение 3.3V

### DHT22 показывает NaN
- Проверьте резистор подтяжки 10K
- Проверьте питание 3.3V
- Подождите 2 секунды между чтениями

### Wi-Fi не подключается
- Проверьте правильность пароля
- Убедитесь что роутер работает на 2.4 GHz (не 5 GHz)
- Сбросьте настройки: откройте `/reset` в браузере
