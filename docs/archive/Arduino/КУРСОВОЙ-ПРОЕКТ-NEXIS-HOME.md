## 🎯 ЦЕЛЬ ПРОЕКТА

Разработать **недорогой, компактный IoT-хаб** для мониторинга параметров окружающей среды в помещении с передачей данных на платформу NEXIS.

### Почему это нужно для NEXIS?

NEXIS Home — будущий модуль умного дома в экосистеме NEXIS. Этот курсовой проект станет **первым физическим устройством** в экосистеме, демонстрируя интеграцию hardware и software.

## 📊 ФУНКЦИОНАЛ УСТРОЙСТВА

### Измеряемые параметры:

| Датчик | Параметр | Диапазон |
|--------|----------|----------|
| **DHT22** | Температура | -40°C ... +80°C |
| **DHT22** | Влажность | 0% ... 100% |
| **BMP280** | Атм. давление | 300 ... 1100 hPa |
| **MQ-135** | Качество воздуха | CO2, NH3, NOx |
| **BH1750** | Освещённость | 1 ... 65535 lx |
| **PIR** | Движение | Да/Нет |

### Возможности:

```
✅ Измерение 6 параметров окружающей среды
✅ Отправка данных на NEXIS сервер каждые 30 сек
✅ Локальный OLED дисплей (128x64)
✅ LED индикация статуса
✅ Звуковое оповещение при тревогах
✅ Кнопка для ручной передачи данных
✅ Web-интерфейс для настройки
✅ OTA обновление прошивки
```

               TX ─┤3           28├─ RST
               RX ─┤4           27├─ EN
      DHT22 Data → ┤5  D1(GPIO5)26├─ 3V3
    PIR Signal  → ┤6  D2(GPIO4)25├─ GND
   Buzzer       → ┤7  D3(GPIO0)24├─ CLK
   Button       → ┤8  D4(GPIO2)23├─ SD0
                  ┤9      GND   22├─ CMD
                  ┤10     3V3   21├─ SD1
 OLED SDA(I2C) ↔ ┤11 D5(GPIO14)20├─ SD2
 OLED SCL(I2C) ↔ ┤12 D6(GPIO12)19├─ SD3

 BMP/BH SCL    ↔ ┤14 D8(GPIO15)17├─ RSV

                   └──────────────┘

### Необходимые библиотеки:

```cpp
// Для Arduino IDE / PlatformIO

#include <ESP8266WiFi.h>        // Wi-Fi для ESP8266
#include <ESP8266HTTPClient.h>  // HTTP клиент
#include <ArduinoJson.h>        // JSON парсер
#include <DHT.h>                // DHT22 датчик
#include <Adafruit_BMP280.h>    // BMP280 датчик
#include <BH1750.h>             // BH1750 датчик
#include <Wire.h>               // I2C протокол
#include <Adafruit_SSD1306.h>   // OLED дисплей
#include <ESP8266WebServer.h>   // Локальный веб-сервер
#include <EEPROM.h>             // Сохранение настроек
#include <ArduinoOTA.h>         // OTA обновление
```

### NEXIS API Endpoints:

```
POST /api/home/sensors          - Отправка данных
GET  /api/home/devices          - Список устройств
GET  /api/home/devices/{id}     - Данные устройства
POST /api/home/devices/register - Регистрация устройства
PUT  /api/home/devices/{id}     - Обновление настроек
```
