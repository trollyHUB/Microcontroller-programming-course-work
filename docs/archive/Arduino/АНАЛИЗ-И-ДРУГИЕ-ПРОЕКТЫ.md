## 📋 ДРУГИЕ ИДЕИ ПРОЕКТОВ ДЛЯ NEXIS + ARDUINO

### 🏠 Категория: Умный дом

#### 1. NEXIS Gate — Умный замок
```
📦 Компоненты: ESP32, RFID RC522, сервопривод, реле
💰 Бюджет: ~15 000 ₸

Функции:
├── Открытие по RFID карте
├── Открытие через приложение NEXIS
├── Временные коды доступа (для гостей)
├── Логирование всех открытий
├── Уведомления владельцу
└── Интеграция с камерой (опц.)

Связь с NEXIS:
├── NEXIS ID для авторизации
├── NEXIS Home для управления
└── NEXIS Notify для уведомлений
```

#### 2. NEXIS Guard — Охранная система
```
📦 Компоненты: ESP32-CAM, PIR датчик, сирена, реле
💰 Бюджет: ~20 000 ₸

Функции:
├── Обнаружение движения (PIR)
├── Фотофиксация при срабатывании
├── Отправка фото в Telegram/NEXIS
├── Сирена с управлением
├── Режимы: дома / ушёл / ночь
└── Таймер автопостановки

Связь с NEXIS:
├── NEXIS Notify — push уведомления
├── NEXIS Cloud — хранение фото
└── NEXIS Home — управление режимами
```

#### 3. NEXIS Light — Умное освещение
```
📦 Компоненты: ESP32, реле модуль, датчик освещённости
💰 Бюджет: ~10 000 ₸

Функции:
├── Управление светом через приложение
├── Расписание вкл/выкл
├── Датчик освещённости (авто режим)
├── Имитация присутствия
├── Сценарии ("Кино", "Вечер", "Утро")
└── Голосовое управление (через NEXIS AI)

Связь с NEXIS:
├── NEXIS Home — центр управления
├── NEXIS AI — голосовые команды
└── NEXIS Scene — сценарии освещения
```

### 📊 Категория: Мониторинг

#### 4. NEXIS Air — Качество воздуха
```
📦 Компоненты: ESP32, CCS811, SDS011, дисплей
💰 Бюджет: ~25 000 ₸

Функции:
├── Измерение CO2 (CCS811)
├── Измерение PM2.5/PM10 (SDS011)
├── Температура и влажность
├── Индекс качества воздуха (AQI)
├── Рекомендации ("Проветрите комнату")
├── Автовключение очистителя воздуха
└── История и графики

Связь с NEXIS:
├── NEXIS Health — данные о здоровье
├── NEXIS Home — автоматика
└── NEXIS AI — рекомендации
```

#### 5. NEXIS Meter — Умный счётчик
```
📦 Компоненты: ESP32, датчик тока SCT-013, дисплей
💰 Бюджет: ~12 000 ₸

Функции:
├── Измерение потребления электричества
├── Подсчёт стоимости (по тарифу)
├── Графики потребления
├── Прогноз счёта на конец месяца
├── Уведомления о превышении
└── Сравнение с прошлым периодом

Связь с NEXIS:
├── NEXIS Pay — прогноз счёта
├── NEXIS Home — управление нагрузкой
└── NEXIS Notify — уведомления
```

## 🎯 РЕКОМЕНДАЦИЯ

### Для курсовой работы рекомендую:

**🏆 NEXIS Home Sensor Hub (базовый)**

Почему:
1. Оптимальная сложность для курсовой
2. Бюджетный (~12 000 ₸)
3. Показательный результат
4. Много документации
5. Реальная интеграция с NEXIS

Расширения (если будет время/желание):
- Добавить датчик CO2 → NEXIS Air
- Добавить реле + вентилятор → автоматика
- Добавить камеру → NEXIS Guard
