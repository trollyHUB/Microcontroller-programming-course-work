# 📋 ОПИСАНИЕ КУРСОВОГО ПРОЕКТА

## «IoT-система мониторинга микроклимата NEXIS Home Sensor Hub»

---

## 🎯 ЦЕЛЬ ПРОЕКТА

Разработать **компактное IoT-устройство** для мониторинга параметров окружающей среды в помещении с передачей данных на веб-сервер и отображением в реальном времени.

---

## 📊 ФУНКЦИОНАЛЬНЫЕ ВОЗМОЖНОСТИ

### Измеряемые параметры:

| № | Параметр | Датчик | Диапазон измерений |
|---|----------|--------|-------------------|
| 1 | Температура воздуха | DHT22 | -40°C ... +80°C (±0.5°C) |
| 2 | Относительная влажность | DHT22 | 0% ... 100% (±2%) |
| 3 | Атмосферное давление | BMP280 | 300 ... 1100 hPa |
| 4 | Качество воздуха | MQ-135 | CO2, NH3, NOx, бензол |
| 5 | Освещённость | BH1750 | 1 ... 65535 люкс |
| 6 | Присутствие человека | PIR HC-SR501 | Да/Нет |

### Возможности системы:

```
✅ Измерение 6 параметров окружающей среды
✅ Локальный OLED-дисплей для отображения данных
✅ Передача данных на сервер по Wi-Fi (каждые 30 сек)
✅ Веб-интерфейс для просмотра данных в браузере
✅ Графики изменения параметров во времени
✅ Звуковое оповещение при превышении порогов
✅ LED-индикация состояния устройства
✅ Настройка через встроенный веб-портал
✅ OTA-обновление прошивки (по воздуху)
```

## 🔧 ТЕХНИЧЕСКИЕ ХАРАКТЕРИСТИКИ

### Аппаратная часть:

| Параметр | Значение |
|----------|----------|
| **Микроконтроллер** | ESP8266 (Tensilica L106, 80 МГц) |
| **Память** | 4 МБ Flash, 80 КБ RAM |
| **Связь** | Wi-Fi 802.11 b/g/n (2.4 ГГц) |
| **Интерфейсы** | I2C, SPI, UART, GPIO, ADC |
| **Питание** | 5V DC (Micro-USB) |
| **Потребление** | ~200 мА (при передаче данных) |
| **Размеры** | ~80 x 60 x 30 мм |

### Программная часть:

| Компонент | Технология |
|-----------|------------|
| **Прошивка МК** | C/C++ (Arduino Framework) |
| **IDE** | PlatformIO / Arduino IDE |
| **Протоколы** | HTTP, REST API, JSON |
| **Веб-сервер** | ESPAsyncWebServer |
| **Backend** | Node.js / Python (опционально) |
| **Frontend** | HTML5, CSS3, JavaScript |
| **База данных** | SQLite / MongoDB (опционально) |
