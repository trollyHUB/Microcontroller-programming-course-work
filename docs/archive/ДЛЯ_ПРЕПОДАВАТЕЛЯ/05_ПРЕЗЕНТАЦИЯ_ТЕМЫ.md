# СЛАЙД 3: ЦЕЛЬ И ЗАДАЧИ

## 🎯 Цель работы:

> Разработать компактное IoT-устройство для мониторинга параметров микроклимата помещения с передачей данных в облако и визуализацией через веб-интерфейс.

## 📋 Задачи:

1. Изучить принципы работы датчиков и микроконтроллера ESP8266
2. Спроектировать аппаратную часть системы
3. Разработать прошивку микроконтроллера
4. Создать веб-интерфейс для отображения данных
5. Протестировать и отладить систему
6. Оформить документацию
