## ✅ ОБОСНОВАНИЕ ВЫБОРА

### Почему выбрана тема «IoT-система мониторинга микроклимата»:

1. **Максимальный балл (9.2/10)** среди всех рассмотренных тем

2. **Соответствие мировым трендам:**
   - Internet of Things (IoT)
   - Smart Home
   - Экологический мониторинг
   - Облачные технологии

3. **Практическая значимость:**
   - Применимо в квартирах, офисах, школах
   - Контроль качества воздуха актуален после COVID-19
   - Энергоэффективность и комфорт

4. **Техническая глубина:**
   - Работа с 6 разными датчиками
   - Wi-Fi и сетевое программирование
   - Веб-разработка (frontend)
   - REST API (backend)

5. **Интеграция с NEXIS:**
   - Первое физическое устройство в экосистеме
   - Демонстрация масштабируемости платформы
   - Потенциал для дипломной работы

6. **Оптимальный бюджет:**
   - ~15,000 тенге — доступно для студента
   - Все компоненты можно купить в Казахстане
