## Выбранная тема курсовой работы

### **«Разработка IoT-системы мониторинга микроклимата помещения на базе ESP8266 с веб-интерфейсом и облачной интеграцией»**

*(Соответствует теме №22 из списка: "Детектор загрязнения окружающего воздуха с функцией отображения на web-сервере")*

---

## Краткое описание проекта

Разработка компактного IoT-устройства **"NEXIS Home Sensor Hub"** для комплексного мониторинга параметров окружающей среды в помещении:

- 🌡️ Температура воздуха
- 💧 Относительная влажность
- 🌀 Атмосферное давление
- 🌬️ Качество воздуха (CO2, NH3, NOx)
- 🔆 Уровень освещённости
- 👤 Детекция движения/присутствия

Данные передаются по Wi-Fi на облачный сервер и отображаются в веб-интерфейсе в реальном времени.
