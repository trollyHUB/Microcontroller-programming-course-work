## Файлы

### Силлабус.pdf — Программа дисциплины (21 стр.)

Официальный силлабус курса MP3304. Подписан деканом, зав. кафедрой, преподавателем.

**Структура курса:**
| Тип занятий | Часы |
|------------|------|
| Лекции | 15 ч. |
| Лабораторные работы | 30 ч. |
| СРО (самостоятельная работа) | 105 ч. |
| **Итого** | **150 ч.** |

**Два модуля:**
- **Модуль 1** — Общая информация о микроконтроллерах
- **Модуль 2** — Управление окружающей средой (датчики, интерфейсы, беспроводная связь)

**Темы лекций (15 недель × 1 час):**
1. Введение: микропроцессоры, микроконтроллеры, история
2. Знакомство с платформой Arduino
3. Среда разработки Arduino IDE, синтаксис C++
4. Цифровой ввод/вывод, ШИМ (PWM)
5. Опрос аналоговых датчиков, АЦП
6. Транзисторы, управляемые двигатели (DC, сервоприводы)
7. USB и последовательный интерфейс (UART)
8. Сдвиговые регистры, светодиодные матрицы
9. Датчики расстояния, SD-карты
10. Шина I2C
11. Шина SPI
12. LCD-дисплеи
13. Радиоуправление и беспроводная связь
14. Аппаратные прерывания и таймеры
15. Итоговое занятие / резерв

**Пререквизиты:** ZhP3302 — Системное программирование (Assembler)  
**Постреквизиты:** KZH4219 — Встроенные системы

### ЛЕКЦИЯ Все.pdf — Все лекции (602 стр.)

Полный конспект всех 15 лекций на **казахском языке** (қазақша).

**Охватываемые темы:**
- История микропроцессоров: Intel 4004 (1971) → современные AMD/Intel
- Архитектура МК: АЛУ, регистры, шины данных/адреса/управления
- RISC vs CISC архитектуры
- Arduino платформа: аппаратная часть, ATmega328P
- Программирование: `setup()`, `loop()`, типы данных, операторы
- `digitalWrite` / `digitalRead` / `analogRead` / `analogWrite`
- ШИМ (PWM): управление яркостью LED и скоростью мотора
- Датчики: потенциометр, температурный датчик, фоторезистор
- Транзисторы как ключи, H-мост для DC-мотора
- Serial UART: `Serial.begin()`, `Serial.print()`, `Serial.read()`
- I2C шина, SPI шина
- Прерывания и таймеры (последние лекции)

> Лекции ведутся на казахском, но примеры кода — на C++ (Arduino), поэтому понять практику можно без перевода.

### Микро контрол лабка все.pdf — Лабораторные работы (68 стр.)

15 лабораторных работ на **казахском и русском** языках. Все на базе Arduino UNO.

| № | Название | Что изучается |
|---|---------|--------------|
| 1 | Маячок (Beacon) | `digitalWrite`, `delay`, базовая схема с LED |
| 2 | Управление яркостью / Терменвокс | ШИМ (`analogWrite`), аналоговый ввод |
| 3 | Ночник | Фоторезистор + условный оператор |
| 4 | Пульсар | Плавное изменение яркости (цикл + ШИМ) |
| 5 | Бегущий огонь | Массивы, цикл `for`, несколько LED |
| 6 | «Плохое пианино» / Миксер | Тон (`tone()`), аналоговый ввод |
| 7 | Кнопочный выключатель | `digitalRead`, `INPUT_PULLUP`, дребезг |
| 8 | «Кнопочные ковбои» | Два игрока, реакция на нажатие |
| 9 | Секундомер | `millis()`, Serial вывод |
| 10 | Счётчик нажатий | Переменные, накопление, `Serial.println` |
| 11 | Комнатный термометр / Метеостанция | Аналоговый датчик температуры, калибровка |
| 12 | Пантограф (сервопривод) | `Servo.h`, `map()`, потенциометр |
| 13 | Тестер батареи | Делитель напряжения, вычисления |
| 14 | USB-управляемый светильник | `Serial.read()`, команды по UART |
| 15 | «Перетягивание каната» | Два игрока, кнопки, счётчик |

> Для NEXIS Wellness Station особенно полезны лабы 2, 7, 9, 11, 12 — датчики, кнопки, таймер, Serial.

### Материал для рб,сс.pdf — Вопросы к рубежному контролю (4 стр.)

Вопросы для **двух рубежных контролей** (РБ1 и РБ2) + вопросы к семестровому контролю (СС).

**Рубежный контроль 1 (~32 вопроса):**
- Архитектура микропроцессора и МК
- CISC/RISC, 16/32-битные МК
- Arduino UNO: питание, пины, ATmega328P
- Язык программирования: типы данных, операторы, функции
- `pinMode`, `digitalWrite`, `digitalRead`, `analogRead`, `analogWrite`
- `millis()`, `delay()`, `tone()`, `shiftOut()`
- `Serial.begin/read/print/write`

**Рубежный контроль 2 (~20+ вопросов):**
- `random()`, побитовые операции
- Сдвиговые регистры, RFID
- Датчики расстояния, SD-карты
- I2C и SPI шины
- LCD-дисплеи
- Беспроводная связь
- Аппаратные прерывания и таймеры

> Это прямое руководство по тому, что нужно знать к экзамену.
