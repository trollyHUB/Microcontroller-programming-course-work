# 🎯 КОНЦЕПЦИЯ ПРОЕКТА

## Почему именно эта тема?

В 2025-2026 году наблюдаются главные тренды:

1. **🏥 Digital Wellness** — мониторинг здоровья стал мейнстримом
2. **⏱️ Productivity Tech** — гаджеты для повышения продуктивности
3. **🌿 Indoor Environment** — качество воздуха в помещениях
4. **🤖 AI-интеграция** — умные рекомендации
5. **📱 Telegram боты** — самый популярный способ уведомлений в СНГ

## Что делает устройство?

NEXIS Wellness Station — это **персональный помощник** на рабочем столе:

### Основные функции:

```
✅ Мониторинг микроклимата (температура, влажность, CO2)
✅ Напоминания о перерывах (Pomodoro Timer)
✅ Отслеживание времени сидения (PIR датчик)
✅ Мониторинг освещённости (для здоровья глаз)
✅ Уровень шума (для концентрации)
✅ Telegram уведомления и команды
✅ Статистика продуктивности за день/неделю
✅ Рекомендации по улучшению рабочей среды
```

# 📱 ИНТЕРФЕЙС УПРАВЛЕНИЯ

## 🤖 Telegram Bot (РЕКОМЕНДУЕТСЯ!)

### Почему Telegram Bot?

| Критерий | Сайт | Приложение | Telegram |
|----------|------|------------|----------|
| Стоимость разработки | Низкая | Высокая | **Очень низкая** |
| Время разработки | 2-3 дня | 2-4 недели | **4-6 часов** |
| Уведомления Push | Сложно | Нормально | **Очень просто** |
| Кроссплатформенность | Да | Нет | **Да** |
| Установка пользователем | Нет | Да | **Нет** |
| Интеграция с ESP32 | Средне | Сложно | **Очень просто** |

### Функции Telegram бота:

```
📊 /status — текущие показатели
📈 /stats — статистика за день/неделю
⏱️ /pomodoro — запуск таймера (25 мин работа / 5 мин отдых)
🔔 /alerts on/off — включить/выключить уведомления
⚙️ /settings — настройки порогов
🌡️ /climate — детальный отчёт по климату
💪 /health — рекомендации по здоровью
📅 /report — еженедельный отчёт
```

### Автоматические уведомления:

```
⚠️ "CO2 повышен (1200 ppm). Проветрите помещение!"
🪑 "Вы сидите уже 2 часа. Время размяться!"
💡 "Освещение низкое (150 lux). Включите лампу!"
🔊 "Высокий уровень шума. Сложно концентрироваться?"
🍅 "Pomodoro завершён! Перерыв 5 минут."
📊 "Дневной отчёт: Работали 6ч, 4 перерыва, климат — хороший"
```
