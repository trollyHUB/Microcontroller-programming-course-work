## 🎯 ЧТО МЫ СДЕЛАЛИ

### Основная задача
Создали **локальный веб-сайт (dashboard)** на Python Flask, который:
- Получает данные с ESP32 по REST API
- Хранит историю в SQLite базе
- Отображает данные в реальном времени через WebSocket
- Имеет красивый интерфейс с графиками, Pomodoro таймером и алертами
- **Всё работает ЛОКАЛЬНО без интернета** — идеально для курсовой!

---

## 📦 ЧТО МЫ НАПИСАЛИ

### 1. **Python Backend (Flask сервер)**
**Файл:** `app.py` (230 строк)

**Функционал:**
- REST API endpoints для получения/отправки данных
- WebSocket для real-time обновлений
- SQLite база данных (nexis.db)
- Система проверки пороговых значений (CO2, температура, свет, шум)
- Система алертов с уровнями severity (warning, danger)
- Логирование Pomodoro циклов
- CORS для локальной сети

**Ключевые маршруты:**
```
POST   /api/data              ← ESP32 отправляет данные
GET    /api/sensors           ← браузер получает последние показания
GET    /api/history?hours=24  ← график за 24 часа
GET    /api/stats             ← статистика дня
GET    /api/alerts            ← последние алерты
POST   /api/pomodoro          ← события Pomodoro
GET    /api/status            ← статус сервера
```

### 2. **Frontend (HTML + CSS + JavaScript)**

#### **HTML (templates/index.html)** — 120 строк
- Структура страницы dashboard
- 6 карточек датчиков
- Интерактивный график
- Pomodoro таймер
- Статистика дня
- Список алертов

#### **CSS (static/css/style.css)** — 280 строк
- **Тёмная тема** по умолчанию
- **Адаптивный дизайн** (работает на телефонах)
- Плавные переходы и анимации
- Цветовая индикация (зелёный/жёлтый/красный)
- CSS переменные для лёгкого изменения темы

#### **JavaScript (static/js/dashboard.js)** — 320 строк
- **WebSocket** для real-time обновлений
- **Chart.js** графики (температура, влажность, CO2, свет)
- **Pomodoro таймер** с управлением (старт/стоп)
- Система уведомлений (toast)
- Автоматическое переключение между метриками
- **Демо-режим** (имитация датчиков, если ESP32 не подключён)
- Проверка пороговых значений и подсветка карточек

### 3. **Прошивка ESP32**
**Файл:** `esp32/main.cpp` (380 строк)

**Функционал:**
- Чтение 6 датчиков: температура, влажность, CO2, свет, шум, движение
- Подключение к WiFi (настраивается в коде)
- Отправка данных на Python-сервер по REST API (каждые 10 сек)
- OLED дисплей (4 страницы)
- **Telegram Bot** (команды /status, /pomodoro, /stop, /help, /ip)
- **RGB LED индикация** (зелёный = OK, жёлтый = предупреждение, красный = опасность)
- Зуммер для уведомлений
- Pomodoro таймер встроенный (25 мин работа, 5 мин перерыв)
- Кнопки управления
- Отладка через Serial Monitor

**Библиотеки:**
- WiFi.h, HTTPClient.h
- UniversalTelegramBot.h (Telegram)
- Adafruit_SSD1306 (OLED)
- DHT.h (температура/влажность)
- BH1750.h (свет)
- ArduinoJson.h (JSON парсинг)

### 4. **PlatformIO конфигурация**
**Файл:** `esp32/platformio.ini`

- Все библиотеки указаны
- Скорость загрузки: 921600 bauds
- Монитор серийного порта: 115200 bauds

## 💡 ГЛАВНЫЕ ОСОБЕННОСТИ

### ✅ WebSocket Real-Time
- Данные обновляются в браузере **мгновенно** при получении с ESP32
- Никакой задержки, всё live
- Неважно сколько браузеров открыто — все видят одно и то же

### ✅ Демо-режим
- Если ESP32 не подключён → сайт **автоматически включает демо**
- Имитация датчиков с реалистичными волнами
- Можешь показывать преподавателю даже без аппаратуры!

- **Зелёный** — всё в норме
- **Жёлтый** — предупреждение (CO2 повышен, мало света)
- **Красный** — опасность (очень высокое давление, слишком жарко)
- История алертов хранится в БД

### ✅ Pomodoro таймер
- 25 мин работа + 5 мин перерыв
- Синхронизация между браузером и платой
- Уведомления в Telegram при завершении цикла
- Статистика: сколько циклов сегодня

### ✅ Локальная сеть
- Работает **БЕЗ интернета**
- ESP32 и компьютер в одной WiFi → готово
- Идеально для защиты перед преподавателем!

### ✅ Адаптивный дизайн
- На компьютере: красивый dashboard
- На телефоне: всё умещается, пальцами управляется

## 🔧 ТЕХНИЧЕСКИЕ ДЕТАЛИ

### Flask маршруты и как они работают

**POST /api/data** (от ESP32)
- Получает JSON с датчиков
- Сохраняет в SQLite
- Проверяет пороги алертов
- Отправляет браузерам через WebSocket
- Возвращает: `{"status":"ok","alerts":0}`

**GET /api/sensors** (для браузера)
- Возвращает последнее показание
- Формат: `{"temperature":23.4,"humidity":47,"co2":850,...}`

**GET /api/history?hours=24**
- Вернёт до 200 точек (прореживание если больше)
- Для графиков в браузере

**GET /api/stats**
- Средние, min/max значения за день
- Количество Pomodoro циклов

### WebSocket события (real-time)

**server → browser:**
```javascript
socket.on('sensor_update', (data) => {...})  // Новые данные с датчиков
socket.on('new_alerts', (alerts) => {...})   // Новые алерты
socket.on('pomodoro_event', (data) => {...}) // Событие таймера
```

### Как работает демо-режим?

```javascript
// Если нет реальных данных → включается демо
if (data && data.temperature) {
  applyData(data);  // Реальные данные
} else {
  startDemo();      // Демо-режим
}

// Функция демо (волнистые синусоиды):
function startDemo() {
  let tick = 0;
  setInterval(() => {
    tick++;
    const demo = {
      temperature: 22 + Math.sin(tick * 0.1) * 2 + Math.random() * 0.3,
      humidity:    48 + Math.sin(tick * 0.07) * 5 + Math.random() * 1,
      co2:         650 + Math.sin(tick * 0.05) * 150 + Math.random() * 20,
      // ...
    };
    applyData(demo);
  }, 3000);
}
```

### Система пороговых значений

```python
THRESHOLDS = {
    'co2':         {'warn': 800,  'bad': 1200, 'unit': 'ppm'},
    'temperature': {'warn': 27,   'bad': 30,   'unit': '°C'},
    'humidity':    {'warn': 65,   'bad': 75,   'unit': '%'},
    'light':       {'warn': 150,  'bad': 50,   'unit': 'lux'},
    'noise':       {'warn': 55,   'bad': 70,   'unit': 'dB'},
}

# Проверка при получении данных:
# Если CO2 > 1200 → красная карточка + алерт в историю
# Если CO2 > 800 → жёлтая карточка
# Иначе → зелёная
```
