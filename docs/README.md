## Что есть в каждой секции

### `NEXIS_Wellness_Station/` — техническая документация

Полная документация IoT-проекта. Создавалась итеративно с января 2026 г. Документы пронумерованы в логическом порядке — от ТЗ до руководства по покупке.

> **Внимание:** Ранние документы (янв–фев 2026) содержат устаревшие данные — DHT22 и OLED SSD1306. Актуальное оборудование подтверждено курсовой работой. Используй `README2_АКТУАЛЬНОЕ_СОСТОЯНИЕ.md` как точку входа.

**Ключевые факты проекта (актуальные, май 2026):**
- Микроконтроллер: **ESP32 DevKit V1**
- Основные датчики: **BME280** (T/H/P, I2C 0x76), **ZM106-VOC** (CO₂/VOC, UART)
- Дополнительные: BH1750 (свет), PIR HC-SR501 (движение), KY-037 (шум), DHT11, MQ-135
- Дисплей: **LCD 1602** (I2C 0x27, PCF8574) — НЕ OLED!
- Индикация: RGB LED, зуммер; Кнопки Mode/OK с аппаратными прерываниями
- Бюджет: **~15 700 ₸** (рекомендуемая конфигурация)
- Усложнения: адаптивные пороги, 5 режимов работы, геймификация, OTA, FreeRTOS

### `Kursovoi/` — методические указания

Официальные МУ кафедры по оформлению и содержанию курсовых работ по PM3304. Два исходных файла (2022 и 2024) + объединённый документ `МУ_КУРСОВАЯ_PM3304_ПОЛНЫЙ.md`.

**Ключевые требования:** 25–35 стр., Times New Roman 14 пт, интервал 1.5, поля 35/10/20/20 мм, доклад 8–10 мин., обязательна презентация PowerPoint. **Список тем: 33 темы** (актуальный список 2024 г.).
